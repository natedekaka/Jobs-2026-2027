# Balikin Lenovo X270 ke Windows Demi Atlas OS — Persiapan Bahan Ajar Informatika Kelas X

---

Jadi ceritanya, saya punya laptop Lenovo X270. Speknya standar, kecil, ringan, cocok buat mobilitas. Udah lama dipake Linux. Tapi tahun pelajaran 2026/2027 ini, ada rencana baru — laptop ini bakal saya jadiin senjata utama buat ngajar Informatika kelas X.

Masalahnya? Materi kelas X banyak yang pakai Windows: Word, Excel, PowerPoint, sampe Canva. Jadi ya mau gak mau, saya harus balikin si X270 ke Windows.

Tapi saya bukan tipikal yang betah Windows bawaan pabrik. Terlalu banyak **bloatware**, berat di RAM, kadang lemot — padahal spek laptop ini pas-pasan buat Windows 10 an. Apalagi buat ngajar, saya pengen sistemnya **responsif, ringan, dan gak lemot pas ditunjukin ke murid**.

Makanya saya milih **Atlas OS**.

---

## Atlas OS Itu Apa?

Sederhananya, Atlas OS itu **Windows yang udah dimodifikasi** — dibuang sampah-sampahnya (bloatware, telemetry, iklan), dioptimalkan biar lebih enteng dan cepat. Cocok buat yang pengen Windows tapi gak kuat sama kelambatan Windows standar.

Proyeknya open-source, legal, dan gratis. Buat yang penasaran, bisa cek langsung di [atlasos.net](https://atlasos.net/).

Yang perlu dicatat: Atlas OS **gak bisa diinstal langsung** dari ISO. Prosesnya: **fresh install Windows 10 dulu**, baru jalanin Atlas Playbook-nya.

---

## Kenapa Pilih Versi 0.4?

Atlas OS sekarang udah sampai versi **0.5.0** (dirilis Oktober 2025), tapi sayangnya versi itu **cuma support Windows 11**.

Karena laptop X270 saya lebih cocok pake Windows 10 (apalagi buat spek yang terbatas), saya pilih **Atlas OS release 0.4** yang kompatibel dengan Windows 10. Ringan, stabil, dan fiturnya udah cukup buat kebutuhan ngajar.

---

## Proses Install — Gak Sampai 2 Jam

Step by stepnya simpel:

1. **Backup data** — karena mau fresh install, semua data dipindah dulu.
2. **Install Windows 10 fresh** — pake bootable USB, proses biasa.
3. **Install Atlas OS** — download AME Wizard + Atlas Playbook, jalankan sesuai panduan di [docs.atlasos.net](https://docs.atlasos.net/).
4. **Restart** — selesai.

Proses Atlas OS-nya sendiri cuma beberapa menit. Yang lama ya install Windowsnya. Total bisa selesai dalam 1-2 jam.

---

## Kesan Setelah Dipasang

Perbedaan langsung kerasa:

- **RAM idle** turun drastis — dari 2,5–3 GB di Windows standar, jadi sekitar **1,5 GB**.
- **Booting cepet** — gak sabar nunggu loading.
- **Gak ada iklan** — gak ada pop-up "OneDrive", "Cortana", "Xbox", dll.
- **Proses ngajar lancar** — buka Office, browser, slide, gak ada lag.

Pokoknya bikin si X270 bernafas lega.

---

## Rencana ke Depan

Laptop Lenovo X270 ini sekarang resmi jadi **alat ajar utama** buat mapel Informatika kelas X. Spesifiknya buat materi:

- Microsoft Word (format teks, tabel, mail merge, daftar isi)
- Microsoft PowerPoint (slide, animasi, presentasi)
- Microsoft Excel (rumus, grafik)

Sisanya — internet, email, Canva — tetap jalan mulus di Atlas OS.

Jadi kalo ada temen-temen guru yang lagi nyari solusi **Windows ringan** buat laptop spek pas-pasan, Atlas OS bisa jadi pilihan. Lumayan, ngajarnya fokus, gak perlu mikirin loading mulu.
