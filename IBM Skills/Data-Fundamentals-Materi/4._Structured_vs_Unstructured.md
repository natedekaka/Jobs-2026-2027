# Data Terstruktur vs Tidak Terstruktur

## Data Terstruktur

Disimpan dalam baris dan kolom.

Contoh:
- Excel
- Database SQL

Kelebihan:
- Mudah dicari
- Mudah dianalisis
- Query cepat

---

## Data Semi-Terstruktur

Mengandung tag atau metadata.

Contoh:
- JSON
- XML

---

## Data Tidak Terstruktur

Tidak ada format yang ditentukan.

Contoh:
- Gambar
- Video
- Email
- Audio
- Postingan media sosial

---

## Perbandingan

| Terstruktur | Tidak Terstruktur |
|-------------|-------------------|
| Tabel | Gambar |
| SQL | Video |
| Terorganisir | Bentuk bebas |
