# Big Data

Big Data mengacu pada kumpulan data yang sangat besar yang tidak dapat diproses secara efisien menggunakan alat tradisional.

## Karakteristik (5 V)

- Volume
- Velocity (kecepatan)
- Variety (keragaman)
- Veracity (keakuratan)
- Value (nilai)

## Sumber

- Media Sosial
- Perangkat IoT
- Sistem Perbankan
- Platform E-commerce
- Kesehatan

## Aplikasi

- Deteksi Penipuan
- Sistem Rekomendasi
- Analisis Prediktif
- Segmentasi Pelanggan
