## 1. Apa itu Data?

Data adalah kumpulan fakta mentah (raw facts), angka, teks, gambar, video, atau observasi yang **belum diolah** menjadi informasi yang bermakna.

Contoh data:
- Nilai siswa
- Harga produk
- Nama pelanggan
- Klik website
- Suhu ruangan

Data adalah fondasi setiap keputusan bisnis. Organisasi mengumpulkan data untuk memahami pelanggan, memperbaiki produk, mengoptimalkan operasi, dan memprediksi tren masa depan.

### Mengapa Data Penting?
Data membantu organisasi:
- Membuat keputusan yang terinformasi
- Memahami perilaku pelanggan
- Mengidentifikasi tren
- Meningkatkan efisiensi
- Mengurangi risiko bisnis
- Meningkatkan pendapatan

### Contoh Dunia Nyata
Platform belanja online mengumpulkan:
- Nama pelanggan
- Produk yang dibeli
- Nilai pesanan
- Metode pembayaran
- Lokasi pengiriman

Dengan menganalisis data ini, perusahaan bisa merekomendasikan produk, mengoptimalkan stok, dan meningkatkan kepuasan pelanggan.

## 2. Data vs Informasi

**Data**: fakta mentah tanpa konteks.
Contoh: `25`, `42`, `89` — angka ini saja tidak bermakna.

**Informasi**: data yang sudah diolah sehingga memberikan makna.
Contoh: Nilai siswa — Rahul 89, Anita 95, Riya 78. Sekarang data menjadi berguna.

| Data | Informasi |
|------|-----------|
| Fakta mentah | Data yang diproses |
| Belum terorganisir | Terorganisir |
| Tanpa konteks | Bermakna |
| Input | Output |

Contoh: Data `1200` → Informasi "Penjualan bulanan = Rp1200".

---

## 3. Jenis-Jenis Data

**Qualitative (Kualitatif)**: data deskriptif (kategori).
Contoh: Jenis kelamin, Kota, Kategori produk, Umpan balik pelanggan.

**Quantitative (Kuantitatif)**: data numerik (angka).
Contoh: Penjualan, Usia, Pendapatan, Laba.

**Discrete (Diskrit)**: nilai yang bisa dihitung (bilangan bulat).
Contoh: Jumlah siswa, Jumlah pesanan.

**Continuous (Kontinu)**: nilai yang diukur (bisa pecahan).
Contoh: Tinggi, Berat, Suhu.

---

## 4. Data Terstruktur, Semi-Terstruktur, dan Tidak Terstruktur

**Structured (Terstruktur)**: disimpan dalam baris dan kolom.
Contoh: Excel, database SQL.
Kelebihan: mudah dicari, mudah dianalisis, query cepat.

**Semi-Structured**: mengandung tag atau metadata.
Contoh: JSON, XML.

**Unstructured (Tidak Terstruktur)**: tidak ada format yang ditentukan.
Contoh: Gambar, Video, Email, Audio, Postingan media sosial.

| Terstruktur | Tidak Terstruktur |
|-------------|-------------------|
| Tabel | Gambar |
| SQL | Video |
| Terorganisir | Bentuk bebas |

## 5. Siklus Hidup Data (Data Lifecycle)

Data bergerak melalui beberapa tahap:

1. **Data Collection (Pengumpulan)** — kumpulkan data dari berbagai sumber: survei, sensor, website, database.
2. **Data Storage (Penyimpanan)** — simpan data dengan aman di database atau cloud.
3. **Data Cleaning (Pembersihan)** — hapus duplikat, koreksi kesalahan, tangani nilai yang hilang.
4. **Data Analysis (Analisis)** — analisis data dengan Excel, SQL, Python, atau Power BI.
5. **Data Visualization (Visualisasi)** — sajikan wawasan dengan grafik, dashboard, laporan.
6. **Decision Making (Keputusan)** — gunakan wawasan untuk mendukung keputusan bisnis.

---

## 6. Big Data

Big Data adalah kumpulan data yang sangat besar sehingga tidak bisa diproses secara efisien dengan alat tradisional.

### Karakteristik (5 V)
- **Volume** — jumlah data sangat besar
- **Velocity** — kecepatan data masuk sangat tinggi
- **Variety** — beragam jenis data
- **Veracity** — keakuratan/kualitas data
- **Value** — nilai yang bisa diambil dari data

### Sumber
Media sosial, perangkat IoT, sistem perbankan, platform e-commerce, kesehatan.

### Aplikasi
- Deteksi penipuan (fraud detection)
- Sistem rekomendasi
- Analisis prediktif
- Segmentasi pelanggan

---

## 7. Proses Analisis Data (Data Analytics Process)

1. **Define the Problem** — pahami tujuan bisnis.
2. **Collect Data** — kumpulkan data yang relevan dari sumber terpercaya.
3. **Clean Data** — tangani nilai hilang, hapus duplikat, standarkan format.
4. **Analyze Data** — gunakan metode statistik dan alat analisis untuk menemukan tren dan menjawab pertanyaan bisnis.
5. **Visualize Results** — buat grafik, diagram, dan dashboard untuk mengkomunikasikan temuan.
6. **Share Insights** — sajikan rekomendasi kepada pemangku kepentingan untuk pengambilan keputusan.

---

## 8. Metode Pengumpulan Data

- **Surveys (Survei)**: kuesioner. Kelebihan: murah, mudah disebar, cocok untuk audiens besar.
- **Interviews (Wawancara)**: interaksi langsung. Kelebihan: informasi detail, bisa klarifikasi jawaban.
- **Observation (Observasi)**: mengamati perilaku/kejadian. Contoh: pergerakan pelanggan di toko, perilaku pengguna website.
- **Sensors & IoT**: perangkat mengumpulkan data real-time otomatis. Contoh: smartwatch, GPS tracker, sensor suhu.
- **APIs**: memungkinkan aplikasi bertukar data. Contoh: Weather API, Google Maps API, Stock Market API.

## 9. Data Cleaning (Pembersihan Data)

Data cleaning adalah proses mengidentifikasi dan memperbaiki kesalahan, inkonsistensi, dan ketidakakuratan dalam dataset. Data yang bersih meningkatkan kualitas analisis.

### Mengapa Penting
- Meningkatkan akurasi data
- Menghapus record duplikat
- Menangani nilai yang hilang
- Menstandarkan format
- Meningkatkan keandalan laporan dan dashboard

Contoh:
| Sebelum | | Sesudah | |
|---------|---|---------|---|
| Customer | City | Customer | City |
| John | Hyderabad | John | Hyderabad |
| John | Hyderabad | Sarah | Bengaluru |
| Sarah | NULL | | |

---

## 10. Menangani Nilai yang Hilang (Missing Values)

Nilai hilang terjadi saat informasi tidak tersedia atau tidak tercatat.

### Penyebab Umum
- Pengguna melewati kolom
- Kesalahan impor data
- Kegagalan sensor
- Kesalahan input manual

### Teknik
1. **Remove Rows (hapus baris)** — berguna jika hanya sedikit record yang hilang.
2. **Replace with Mean (ganti dengan rata-rata)** — cocok untuk kolom numerik.
   Contoh: `20, 25, NULL, 30` → rata-rata = 25 → `20, 25, 25, 30`
3. **Replace with Median** — lebih disukai bila data mengandung outlier (pencilan).
4. **Replace with Mode** — cocok untuk data kategorikal.

## 11. Data Duplikat (Duplicate Data)

Record duplikat terjadi saat informasi yang sama muncul beberapa kali.

### Masalah yang Ditimbulkan
- Analisis salah
- Total membengkak
- Laporan menyesatkan

Contoh:
| Order ID | Customer | → setelah dihapus duplikat |
|----------|----------|----------------------------|
| 1001 | Alice | 1001 | Alice |
| 1001 | Alice | | |

### Best Practices
- Periksa ID unik
- Hapus duplikat persis (exact duplicate)
- Tinjau duplikat parsial dengan hati-hati
