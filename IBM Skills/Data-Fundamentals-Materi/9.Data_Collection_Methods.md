# Metode Pengumpulan Data

## Survei

Kumpulkan jawaban menggunakan kuesioner.

Kelebihan:
- Hemat biaya
- Mudah disebarkan
- Cocok untuk audiens besar

---

## Wawancara

Interaksi langsung dengan peserta.

Kelebihan:
- Informasi yang detail
- Klarifikasi jawaban

---

## Observasi

Mengumpulkan data dengan mengamati perilaku atau kejadian.

Contoh:
- Pergerakan pelanggan di toko
- Perilaku pengguna website

---

## Sensor dan IoT

Perangkat secara otomatis mengumpulkan data real-time.

Contoh:
- Smartwatch
- Pelacak GPS
- Sensor suhu

---

## API

Application Programming Interface (Antarmuka Pemrograman Aplikasi) memungkinkan aplikasi untuk bertukar data.

Contoh:
- Weather API (API Cuaca)
- Google Maps API
- Stock Market API (API Pasar Saham)
