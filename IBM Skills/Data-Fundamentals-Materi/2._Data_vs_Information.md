# Data vs Informasi

## Data

Fakta mentah tanpa konteks.

Contoh:

25
42
89

Angka-angka ini saja tidak bermakna.

---

## Informasi

Informasi adalah data yang sudah diolah sehingga memberikan makna.

Contoh:

Nilai Siswa

Rahul - 89

Anita - 95

Riya - 78

Sekarang data menjadi berguna.

---

## Perbedaan

| Data | Informasi |
|------|-----------|
| Fakta mentah | Data yang diproses |
| Belum terorganisir | Terorganisir |
| Tanpa konteks | Bermakna |
| Input | Output |

---

## Contoh

Data:

1200

Informasi:

Penjualan Bulanan = Rp1200
