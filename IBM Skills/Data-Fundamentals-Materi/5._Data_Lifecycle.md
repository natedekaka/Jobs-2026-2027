# Siklus Hidup Data

Siklus Hidup Data menggambarkan bagaimana data bergerak melalui berbagai tahap.

## 1. Pengumpulan Data

Kumpulkan data dari berbagai sumber.

Contoh:
- Survei
- Sensor
- Website
- Database

---

## 2. Penyimpanan Data

Simpan data dengan aman di database atau cloud storage.

---

## 3. Pembersihan Data

Hapus duplikat, koreksi kesalahan, dan tangani nilai yang hilang.

---

## 4. Analisis Data

Analisis data menggunakan Excel, SQL, Python, atau Power BI.

---

## 5. Visualisasi Data

Sajikan wawasan menggunakan grafik, dashboard, dan laporan.

---

## 6. Pengambilan Keputusan

Gunakan wawasan untuk mendukung keputusan bisnis.
