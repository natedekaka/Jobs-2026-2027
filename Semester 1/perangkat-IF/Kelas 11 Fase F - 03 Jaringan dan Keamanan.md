# Rancangan Pembelajaran Terdiferensiasi — Fase F Kelas 11
## Materi: Konsep Sistem dan Keamanan Jaringan Komputer

---

### 1. Tujuan Pembelajaran

1.1 Mengenali berbagai model jaringan komputer (LAN, MAN, WAN, *client-server*, *peer-to-peer*, *cloud computing*).  
1.2 Memahami mekanisme pengiriman data antar perangkat dalam jaringan komputer.  
1.3 Melakukan *troubleshooting* permasalahan jaringan komputer sederhana.  
1.4 Memahami konsep dan konfigurasi keamanan lanjut konektivitas jaringan.  
1.5 Merancang kebutuhan sistem komputer sesuai kebutuhan pengguna.  
1.6 Memahami pemanfaatan platform *lokapasar*, perbankan digital, dan dompet digital beserta aspek keamanannya.

---

### 2. Kompetensi Prasyarat

| No | Kompetensi Prasyarat | Keterkaitan |
|----|----------------------|-------------|
| 1 | Peserta didik memahami perangkat keras komputer dan konektivitas dasar (Fase E) | Dasar untuk memahami model jaringan |
| 2 | Peserta didik menggunakan internet sehari-hari | Pengalaman empiris untuk memahami konsep jaringan |
| 3 | Peserta didik memahami keamanan dasar akun (Fase E) | Prasyarat untuk keamanan lanjut |

---

### 3. Asesmen Awal

#### 3.1 Instrumen Asesmen Awal

**Bentuk:** Kuis pengalaman jaringan + soal pemahaman konsep + praktik singkat.

**Kuis Pengalaman:**
- [ ] Saya tahu perbedaan LAN dan WAN
- [ ] Saya pernah mengatur *setting* WiFi sendiri
- [ ] Saya tahu apa itu IP *address*
- [ ] Saya pernah menggunakan *cloud storage* (Google Drive, OneDrive, dll)
- [ ] Saya tahu cara mengecek apakah komputer terhubung ke jaringan (*ping*)

**Soal Konsep:**
1. "Apa yang terjadi ketika kamu mengetik alamat website di browser lalu menekan Enter? Jelaskan secara singkat!"
2. "Apa perbedaan jaringan *client-server* dengan *peer-to-peer*?"
3. "Sebutkan 3 contoh platform *fintech* (lokapasar/perbankan digital/dompet digital) yang kamu ketahui!"

**Praktik Singkat:**
> "Buka *Command Prompt*/*Terminal*, ketik `ipconfig` (Windows) atau `ifconfig` (Linux/macOS), dan tuliskan alamat IP komputer kamu!"

#### 3.2 Kriteria Kesiapan Belajar

| Kondisi | Kategori | Tindak Lanjut |
|---------|----------|---------------|
| Mencentang ≤ 1 item, jawaban konsep belum tepat, belum bisa praktik | **Kurang Siap** | Pengenalan jaringan dari pengalaman sehari-hari, analogi pos/sistem pengiriman paket |
| Mencentang 2-3 item, jawaban sebagian benar, praktik terbimbing | **Cukup Siap** | Eksplorasi model jaringan dan simulasi pengiriman data |
| Mencentang ≥ 4 item, jawaban benar, praktik mandiri | **Sudah Siap** | *Troubleshooting* kasus nyata + konfigurasi keamanan lanjut |

### 4. Rancangan Diferensiasi

#### 4.1 Diferensiasi Konten

| Kelompok | Sumber Belajar | Kompleksitas |
|----------|---------------|--------------|
| **Kurang Siap** | Infografis model jaringan + video animasi "bagaimana internet bekerja" + poster perangkat jaringan | Visual, analogi, istilah minimal |
| **Cukup Siap** | Modul jaringan + diagram topologi + tutorial *command line* dasar (*ping*, *tracert*, *ipconfig*) | Semi-teknis, langkah demi langkah |
| **Sudah Siap** | Dokumentasi teknis TCP/IP + studi kasus konfigurasi jaringan + artikel keamanan *cyber* | Teknis, analitis, mendalam |

#### 4.2 Diferensiasi Proses

| Kelompok | Aktivitas Pembelajaran | Pendampingan |
|----------|------------------------|--------------|
| **Kurang Siap** | Simulasi "pos paket data" — peserta didik berperan sebagai paket data yang berjalan dari router ke router | Didampingi, belajar sambil bergerak |
| **Cukup Siap** | Praktik *command line*: *ping*, *tracert*, *nslookup*; membuat diagram topologi jaringan sekolah; diskusi keamanan *fintech* | *Scaffolding* dengan lembar perintah |
| **Sudah Siap** | *Troubleshooting* kasus jaringan (simulasi kabel putus, IP *conflict*, DNS *error*); konfigurasi *firewall* sederhana; analisis keamanan platform *fintech* | Mandiri, pendidik sebagai konsultan |

#### 4.3 Diferensiasi Produk

| Kelompok | Bentuk Produk | Kriteria |
|----------|--------------|----------|
| **Kurang Siap** | Poster "Perjalanan Data di Internet" bergambar (dari komputer pengirim ke penerima) | Menunjukkan 3 komponen: pengirim, jaringan, penerima |
| **Cukup Siap** | Diagram topologi jaringan sekolah/rumah + laporan hasil *ping*/*tracert* + tabel keamanan platform digital | Diagram benar + data perintah + analisis keamanan |
| **Sudah Siap** | Laporan *troubleshooting* jaringan (masalah → diagnosis → solusi) + rekomendasi konfigurasi keamanan untuk UKM | Diagnostik sistematis + rekomendasi teknis |

---

### 5. Pengelompokan Fleksibel

- Praktik *command line* dilakukan berpasangan untuk saling membantu.
- Simulasi jaringan dilakukan dalam kelompok besar dengan peran berbeda (router, client, server, paket data).
- Kelompok analisis keamanan *fintech* bersifat heterogen agar diskusi lebih kaya.
