# Rubrik Penilaian Sumatif — Kelas 11 Fase F
## Algoritma dan Pemrograman Lanjut

| No | Kompetensi | Rendah (75–84) | Sedang (85–94) | Tinggi (95–100) |
|----|-----------|----------------|----------------|-----------------|
| 1 | Mengembangkan program terstruktur | Program monolitik dalam 1 blok utama | Program dengan 3–4 fungsi/prosedur | Program modular dengan fungsi reusable + parameter |
| 2 | Menggunakan library eksternal | Belum menggunakan library | Menggunakan 1 library standar (math, random) | Menggunakan 2+ library + library pihak ketiga |
| 3 | Menerapkan error handling | Program crash saat input salah | Menggunakan try-catch dasar | Error handling komprehensif + logging + user-friendly message |
| 4 | Memperhatikan kualitas kode | Kode berfungsi tetapi tidak rapi | Kode rapi + naming konvensi + komentar | Kode rapi + dokumentasi + coding standar + reuseable |
| 5 | Menggunakan struktur data kompleks | Menggunakan list 1 dimensi | Menggunakan list 2D / dictionary | Menggunakan nested struktur data + memilih struktur tepat |
| 6 | Melakukan debugging dan pengujian | Tidak melakukan pengujian sistematis | Menguji dengan beberapa kasus input | Unit test + boundary test + debugging log |
