# Rubrik Penilaian Sumatif — Kelas 10 Fase E
## Model dan Simulasi Input-Proses-Output (Arsitektur Von Neumann & Sistem Operasi)

| No | Kompetensi | Rendah (75–84) | Sedang (85–94) | Tinggi (95–100) |
|----|-----------|----------------|----------------|-----------------|
| 1 | Menjelaskan arsitektur Von Neumann | Menyebut 1–2 komponen utama (input, CPU, output) tanpa fungsi | Menyebut 3–4 komponen utama dengan fungsi masing-masing | Menyebut semua komponen (ALU, CU, register, memori) + menjelaskan interaksinya |
| 2 | Menggambarkan alur IPO | Alur tidak runtut atau terbalik | Alur runtut: input → proses → output, dengan label sederhana | Alur runtut + detail eksekusi instruksi di CPU + peran memori |
| 3 | Membedakan jenis sistem operasi | Menyebut 1–2 jenis OS (Windows, Android) | Menyebut 3 jenis OS (desktop, mobile, embedded) + contoh | Menyebut 4 jenis OS (desktop, mobile, embedded, server) + karakteristik masing-masing |
| 4 | Memahami peran sistem operasi | Menyebut 1 peran OS (menjalankan aplikasi) | Menyebut 2–3 peran OS (manajemen memori, proses, antarmuka) | Menyebut 4–5 peran OS + simulasi CLI/GUI |
| 5 | Simulasi dasar pengelolaan proses | Membuka/menutup aplikasi dengan panduan | Mengamati penggunaan CPU/RAM di Task Manager mandiri | Menavigasi sistem file via CLI + mengidentifikasi proses berjalan |
