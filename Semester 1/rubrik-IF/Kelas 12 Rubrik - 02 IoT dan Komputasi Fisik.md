# Rubrik Penilaian Sumatif — Kelas 12 Fase F
## IoT dan Komputasi Fisik

| No | Kompetensi | Rendah (75–84) | Sedang (85–94) | Tinggi (95–100) |
|----|-----------|----------------|----------------|-----------------|
| 1 | Memahami konsep IoT dan arsitekturnya | Menjelaskan IoT sebagai "perangkat terhubung internet" | Menjelaskan arsitektur IoT (sensor → prosesor → cloud → aplikasi) | Menjelaskan arsitektur + protokol (MQTT, HTTP, CoAP) + topologi |
| 2 | Merangkai komponen IoT (sensor, aktuator) | Merangkai LED/LDR dengan panduan | Merangkai mandiri sensor suhu + LED/buzzer | Merangkai multi-sensor + aktuator + konektivitas WiFi |
| 3 | Memprogram mikrokontroler | Memodifikasi kode template (ganti nilai/pin) | Menulis kode mandiri: baca sensor → proses → aktuator | Kode mandiri + koneksi cloud + fitur tambahan (alert, dashboard) |
| 4 | Mengirim data ke platform cloud | Menampilkan data di serial monitor | Mengirim data ke cloud (ThingSpeak/Blynk) | Dashboard cloud real-time + visualisasi data + notifikasi otomatis |
| 5 | Memahami keamanan IoT | Menyadari bahwa IoT bisa diretas | Menyebut 2–3 risiko keamanan IoT | Menerapkan langkah pengamanan (enkripsi, autentikasi, update firmware) |
