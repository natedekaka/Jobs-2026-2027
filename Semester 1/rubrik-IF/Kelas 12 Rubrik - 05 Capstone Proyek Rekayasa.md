# Rubrik Penilaian Sumatif — Kelas 12 Fase F
## Proyek Capstone Rekayasa Perangkat Lunak

| No | Kompetensi | Rendah (75–84) | Sedang (85–94) | Tinggi (95–100) |
|----|-----------|----------------|----------------|-----------------|
| 1 | Perencanaan proyek | Rencana minimal: judul, tujuan, fitur utama | Rencana lengkap: analisis masalah, fitur, jadwal, pembagian peran, wireframe | Rencana lengkap + user persona + use case diagram + analisis risiko + milestone |
| 2 | Implementasi teknis | 1–2 fitur utama berfungsi, masih ada error | Semua fitur utama berfungsi, error minimal | Semua fitur berfungsi + optimal + error handling + input validasi |
| 3 | Kualitas produk | UI sederhana, navigasi kurang intuitif | UI rapi, navigasi jelas, responsif | UI/UX profesional, responsif, accessible, user-friendly |
| 4 | Dokumentasi | Readme minimal (judul + deskripsi) | Readme + dokumentasi teknis (cara instalasi, fitur) | Dokumentasi lengkap: readme, technical docs, user guide, deployment guide |
| 5 | Presentasi dan demonstrasi | Presentasi terbaca, demo kurang lancar | Presentasi jelas + demo berjalan + menjawab pertanyaan | Presentasi profesional + demo lancar + argumen kuat + antisipasi pertanyaan |
| 6 | Refleksi dan pengembangan | Refleksi singkat tanpa rencana lanjutan | Refleksi proses + hasil + rencana perbaikan | Refleksi mendalam + analisis kegagalan/keberhasilan + roadmap pengembangan |
| 7 | Kerja sama tim | Kontribusi pasif, mengerjakan tugas yang diberikan | Aktif dalam tugas kelompok, komunikasi baik | Memimpin, memfasilitasi, mentoring anggota lain, resolusi konflik |
