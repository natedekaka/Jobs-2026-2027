# Rubrik Penilaian Sumatif — Kelas 11 Fase F
## Pengolahan Data Bervolume Besar dan Analisis Data

| No | Kompetensi | Rendah (75–84) | Sedang (85–94) | Tinggi (95–100) |
|----|-----------|----------------|----------------|-----------------|
| 1 | Mengolah data dengan spreadsheet | Input data + rumus dasar (SUM, AVERAGE) | Fungsi lanjutan (VLOOKUP, Pivot Table, IF) | Pivot Table + grafik dinamis + dashboard interaktif |
| 2 | Memanfaatkan sumber data terbuka | Menggunakan 1 sumber data yang diberikan | Mencari sendiri 1–2 sumber data terpercaya | Memilih 3+ sumber data terpercaya + membandingkan kualitas data |
| 3 | Membuat visualisasi data | 1 grafik sederhana (batang/garis) | 2–3 grafik variatif + pemilihan jenis grafik tepat | Dashboard multi-visualisasi + storytelling data |
| 4 | Menarik kesimpulan dari data | Kesimpulan deskriptif (apa yang terlihat) | Kesimpulan analitis (mengapa, tren, pola) | Kesimpulan + rekomendasi berbasis data |
| 5 | Memverifikasi konten digital | Memeriksa 1 sumber | Verifikasi teks + gambar dengan 2–3 sumber | Verifikasi teks, gambar, video + lateral reading + dokumentasi |
