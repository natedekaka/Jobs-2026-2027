## Langkah Pembelajaran

### Pembukaan (10 menit)

| Kegiatan | Waktu |
|---|---|
| 1. Salam, doa, cek kehadiran | 2 menit |
| 2. **Review tugas**: Tanya 2–3 siswa — "Tunjukkin screenshot 2FA-mu! Ada kendala?" | 4 menit |
| 3. **Apersepsi**: Guru minta siswa buka Google dan ketik nama mereka sendiri. "Berapa banyak informasi tentangmu yang muncul? Semua itu data pribadimu!" | 2 menit |
| 4. Sampaikan tujuan: hari ini kita **audit** dan **kunci** privasi akun | 2 menit |

### Inti (65 menit)

#### Memahami (berkesadaran, menggembirakan) — 15 menit

1. **Data Pribadi & Jejak Digital (5 menit)**

   | Jenis Data | Contoh | Risiko Jika Bocor |
   |---|---|---|
   | **Pribadi umum** | Nama, foto profil, hobi | Profiling, spam |
   | **Pribadi sensitif** | NIK, alamat, no HP, email | Penipuan, doxxing |
   | **Pribadi rahasia** | Password, PIN, data medis | Peretasan, pencurian identitas |
   | **Jejak digital** | Riwayat search, lokasi, like | Profiling iklan, manipulasi |

   **Statistik:** 60% remaja pernah membagikan lokasi real-time di media sosial.

2. **Filter Konten (5 menit)**

   | Filter | Fungsi | Cara Aktifkan |
   |---|---|---|
   | **SafeSearch Google** | Menyaring konten dewasa | google.com/preferences |
   | **YouTube Restricted Mode** | Menyaring video tidak pantas | Account → Settings → Restricted Mode |
   | **Parental Control (OS)** | Membatasi aplikasi & waktu | Screen Time (iOS) / Family Link (Android) |
   | **DNS Filtering** | Memblokir situs negatif | OpenDNS Family Shield (208.67.222.123) |
   | **Instagram Sensitive Content** | Filter konten sensitif | Settings → Account → Sensitive Content |

3. **Audit Keamanan Akun (5 menit)**

   5 area yang harus dicek secara berkala:
   | Area | Yang Dicek | Level Risiko |
   |---|---|---|
   | A. **Password** | Kuat? Unik? | 🔴 Tinggi |
   | B. **2FA** | Sudah aktif? | 🔴 Tinggi |
   | C. **Privasi** | Siapa bisa lihat postingan? | 🟡 Sedang |
   | D. **Perangkat** | Perangkat apa yang login? | 🟡 Sedang |
   | E. **Aktivitas** | Ada login mencurigakan? | 🟢 Rendah |

#### Mengaplikasi (bermakna, menggembirakan) — 40 menit

4. **Aktivitas 1: Audit Keamanan Akun (20 menit) — Individu**

   **Instruksi: Buka pengaturan keamanan akun Google (myaccount.google.com) dan beberapa platform lain.**

   | Area | Yang Harus Dicek | Catatan |
   |---|---|---|
   | A. **Password** | Security → Password Checkup | Ada password bocor? |
   | B. **2FA** | Security → 2-Step Verification | Sudah aktif? |
   | C. **Perangkat** | Security → Your devices | Ada perangkat asing? |
   | D. **Aktivitas** | Security → Recent security events | Ada login mencurigakan? |
   | E. **Aplikasi pihak ketiga** | Security → Third-party apps | Aplikasi apa yang punya akses ke akunmu? |

   **Platform lain (pilih minimal 2):**
   - **Instagram**: Settings → Privacy → Account Privacy (Public/Private)
   - **Instagram**: Settings → Security → Login Activity
   - **TikTok**: Settings → Privacy → Personalized ads
   - **WhatsApp**: Settings → Account → Privacy → Last seen, Profile photo, Status

5. **Aktivitas 2: Konfigurasi Privasi & Filter Konten (20 menit)**

   **A. Privasi Google (10 menit)**
   | Langkah | Target |
   |---|---|
   | 1. Buka **myaccount.google.com** → **Data & Privacy** | |
   | 2. **Web & App Activity** → matikan / set auto-delete 3 bulan | |
   | 3. **Location History** → matikan | |
   | 4. **YouTube History** → matikan / auto-delete | |
   | 5. **Ad personalization** → matikan (supaya iklan tidak profiling) | |

   **B. Filter Konten (10 menit)**
   - **SafeSearch**: google.com/preferences → centang Turn on SafeSearch
   - **YouTube Restricted Mode**: Account → Settings → Restricted Mode → On
   - **Instagram**: Settings → Account → Sensitive Content Control → Less
   - **DNS Filtering (demo)**: Setting DNS ke OpenDNS Family Shield di router — blokir otomatis situs negatif

#### Merefleksi (berkesadaran, bermakna) — 10 menit

6. **Rencana Perbaikan (5 menit)**
   - Tulis di LKPD: 3 hal yang akan segera diperbaiki
   - Prioritas: mana yang paling kritis?

7. **Refleksi Individu (5 menit)**
   - Seberapa rentan akunmu sebelum pertemuan ini?
   - Satu hal paling mengejutkan tentang data pribadimu
   - Skala pemahaman: ___ / 10

### Penutup (15 menit)

| Kegiatan | Waktu |
|---|---|
| 1. Rangkuman: "Privasi bukan bawaan — harus diatur. Audit akun secara berkala!" | 3 menit |
| 2. Tanya jawab | 5 menit |
| 3. **Tugas**: Selesaikan audit & konfigurasi untuk 1 platform lain (TikTok/IG/WA/X) — catat hasilnya | 3 menit |
| 4. Sampaikan pertemuan depan: Konsep Kualitas Data & GIGO (Bagian 5) | 2 menit |
| 5. Doa & salam | 2 menit |

## Asesmen

### Rubrik Formatif — LKPD Audit

| Kriteria | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **Audit 5 area** | < 2 area dicek | 2–3 area dicek | 4 area dicek | 5 area dicek + catatan |
| **Konfigurasi privasi** | Tidak ada perubahan | 1–2 pengaturan diubah | 3–4 diubah | > 4 diubah + dipahami |
| **Filter konten** | Tidak diaktifkan | 1 filter aktif | 2 filter aktif | 3+ filter aktif |
| **Rencana perbaikan** | Tidak ada | Rencana tidak jelas | 1–2 prioritas jelas | 3 prioritas + timeline |
