### A. DATA PRIBADI & JEJAK DIGITAL

#### Jenis Data Pribadi

| Klasifikasi | Contoh | Risiko |
|---|---|---|
| **Umum** | Nama, hobi, foto profil | Spam, profiling iklan |
| **Sensitif** | NIK, alamat, no HP, email | Penipuan, doxxing, spam |
| **Rahasia** | Password, PIN, data kesehatan | Peretasan, pencurian identitas |

#### Jejak Digital Aktif vs Pasif

| Jenis | Contoh | Bisa Dihapus? |
|---|---|---|
| **Aktif** (sengaja diunggah) | Posting IG, komentar, tweet | Ya — manual |
| **Pasif** (terekam otomatis) | Riwayat search, lokasi, like | Sebagian — atur auto-delete |

#### Mengapa Perusahaan Mengumpulkan Datamu?
1. **Iklan tertarget** — tahu minatmu → iklan relevan
2. **Rekomendasi** — YouTube, TikTok, Netflix
3. **Riset** — tren pengguna, pengembangan produk

> "Jika produk gratis, kamu adalah produknya."

### C. FILTER KONTEN

#### 1. SafeSearch Google

Menyaring konten dewasa dari hasil pencarian Google.

**Cara aktifkan:**
- google.com/preferences → centang **Turn on SafeSearch**
- Atau: google.com → Settings → SafeSearch → Filter

#### 2. YouTube Restricted Mode

Menyaring video yang mungkin tidak pantas.

**Cara aktifkan:**
- YouTube → Profile → Settings → General → Restricted Mode → On
- Atur di tingkat akun atau browser

#### 3. Parental Control (OS)

| Platform | Alat | Fungsi |
|---|---|---|
| **Android** | Google Family Link | Batasi aplikasi, waktu layar, pembelian |
| **iOS / iPadOS** | Screen Time | Batasi konten, aplikasi, waktu |
| **Windows** | Microsoft Family Safety | Filter web, batasi waktu, pantau aktivitas |
| **Router** | OpenDNS Family Shield | Blokir situs dewasa di jaringan |

**OpenDNS Family Shield:**
- DNS primer: `208.67.222.123`
- DNS sekunder: `208.67.220.123`
- Blokir otomatis situs dewasa, phishing, malware

#### 4. Pembatasan Konten di Aplikasi

| Aplikasi | Fitur | Cara |
|---|---|---|
| **Instagram** | Sensitive Content Control | Settings → Account → Sensitive Content → Less |
| **TikTok** | Digital Wellbeing | Settings → Digital Wellbeing → Restricted Mode |
| **Twitter/X** | Sensitive Content | Settings → Privacy → Content you see |

### D. AUDIT KEAMANAN AKUN

#### 5 Area Audit Berkala

| Area | Platform | Yang Dicek | Frekuensi |
|---|---|---|---|
| **Password** | Google Password Checkup | Lemah? Bocor? Dipakai ulang? | 1 bulan |
| **2FA** | Pengaturan keamanan | Aktif? Metode apa? | 1 bulan |
| **Perangkat** | myaccount → Security → Devices | Ada perangkat asing? | 1 minggu |
| **Aktivitas** | myaccount → Security → Events | Ada login mencurigakan? | 1 minggu |
| **Aplikasi pihak ketiga** | myaccount → Security → Apps | Aplikasi apa yang punya akses? | 3 bulan |

#### Tanda Akun Dibobol

| Tanda | Yang Harus Dilakukan |
|---|---|
| Email "login dari perangkat baru" bukan kamu | Segera ganti password + cek 2FA |
| Postingan aneh di akunmu | Ganti password + logout semua perangkat |
| Ada aplikasi tidak dikenal di daftar akses | Hapus akses aplikasi tersebut |
| Password tidak bisa masuk | Gunakan "Forgot Password" — segera |

---

### E. RANGKUMAN

1. **Data pribadi** adalah aset — lindungi dengan pengaturan privasi
2. **Filter konten** aktifkan di semua platform (SafeSearch, Restricted Mode)
3. **Audit akun** secara berkala: password, 2FA, perangkat, aktivitas, aplikasi
4. **Rencana perbaikan** — prioritas dan lakukan segera
