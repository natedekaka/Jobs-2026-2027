### PERTEMUAN 1: PENGANTAR SISTEM KOMPUTER

|---|---|

| **Klasifikasi** | Berdasarkan ukuran, fungsi, dan pengguna |

---

### PERTEMUAN 2: MODEL VON NEUMANN & IPO

| Komponen | Fungsi |
|---|---|
| **Input** | Memasukkan data (keyboard, mouse, sensor) |
| **CPU** | ALU (aritmatika/logika), CU (kontrol), Register |
| **Memori** | RAM (sementara), ROM (tetap), Cache, Storage |
| **Output** | Menampilkan hasil (monitor, printer, speaker) |
| **Bus** | Jalur data antar komponen |

**Alur IPO:** Input → Proses (CPU + Memori) → Output
**Von Neumann:** Program dan data disimpan di memori yang sama.

---

### PERTEMUAN 3: SIMULASI DINAMIKA IPO

- Data mengalir: Keyboard → CPU → RAM → CPU → Layar
- **Siklus Fetch-Decode-Execute:** CPU mengambil instruksi → mengartikan → menjalankan
- Analisis IPO pada aktivitas sehari-hari (mengetik, main game, edit video)

**Bagian OS:** Kernel (inti), Shell (antarmuka), File System
