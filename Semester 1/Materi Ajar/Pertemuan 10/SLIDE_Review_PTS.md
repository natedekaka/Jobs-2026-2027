## 1. Sistem Komputer (Pert 1–2)

**Model Von Neumann:**
- Input → CPU (ALU + CU) → Output
- Program & data di **memori yang sama** (RAM)

| Komponen | Fungsi |
|---|---|
| CPU | ALU (hitung), CU (kontrol) |
| RAM | Memori sementara |
| ROM | Firmware/BIOS |
| Storage | HDD/SSD — simpan permanen |

---

## 2. Simulasi IPO (Pert 3)

### Siklus CPU: Fetch → Decode → Execute

**Contoh alur mengetik huruf "A":**
1. **Input:** Keyboard ditekan
2. **Proses:** CPU terima sinyal → ambil instruksi OS → kirim ke kartu grafis
3. **Output:** Huruf "A" muncul di layar

---

## 3. Sistem Operasi (Pert 4)

### Fungsi OS:
- 🧠 Manajemen proses (multitasking)
- 💾 Manajemen memori (alokasi RAM)
- 📁 Manajemen file
- 🖥️ Antarmuka pengguna (GUI/CLI)

**Contoh OS:** Windows, Linux, macOS, Android, iOS

**Struktur OS:** Kernel (inti) → Shell (penghubung) → User

## Tips Mengerjakan

2. **PG:** eliminasi jawaban yang pasti salah
3. **Esai:** jawab dengan sistematis (poin-poin)

5. **Periksa ulang** sebelum kumpul
