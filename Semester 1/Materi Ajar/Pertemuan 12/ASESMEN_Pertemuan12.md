## A. RUBRIK PENILAIAN LKPD

### A. Cek Keamanan Password (Bobot 25%)

| Kriteria | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Memahami kekuatan password | Tidak mengisi | Mengisi tabel sebagian | Mengisi lengkap | Lengkap + analisis perbedaan |
| Password Checkup | Tidak cek | Cek tanpa catat | Cek + catat | Cek + catat + rencana perbaikan |

### B. Generate Password Baru (Bobot 30%)

| Aspek | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Menggunakan password generator | Tidak | Mencoba | Generate 1–2 | Generate 3 + variasi panjang |
| Prioritas penggantian | Tidak ada rencana | Rencana tidak jelas | Prioritas jelas | Prioritas + timeline |

### C. Aktivasi 2FA (Bobot 35%)

| Aspek | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Status 2FA | Belum aktif | Aktif di 1 akun (SMS) | Aktif di ≥ 2 akun | App + backup code |
| Backup code | Tidak ada | Ada tapi tidak disimpan aman | Disimpan aman | Disimpan + rencana jika HP hilang |

### D. Refleksi & Tugas (Bobot 10%)

| Aspek | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Refleksi | Tidak diisi | Diisi minimal | Refleksi cukup | Refleksi mendalam + komitmen |
| Tugas rumah | Tidak dikerjakan | Screenshot tanpa backup code | Screenshot + backup code | Lengkap + sudah terverifikasi |
