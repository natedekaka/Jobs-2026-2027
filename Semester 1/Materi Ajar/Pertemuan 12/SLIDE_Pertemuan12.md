# TUJUAN PEMBELAJARAN

1. ✅ Membedakan password kuat vs lemah
2. ✅ Menggunakan password manager
3. ✅ Mengaktifkan 2FA di akun sendiri

---

## Kenapa Password Penting?

**Fakta:**
- 🔴 81% pelanggaran data = password lemah
- 🔴 65% orang pakai password SAMA di semua akun
- 🔴 Password `123456` masih nomor 1 di Indonesia

> "Password lemah = undangan untuk diretas"

---

## Ciri Password Kuat

| ❌ Lemah | ✅ Kuat |
|---|---|
| < 8 karakter | ≥ 12 karakter |
| Huruf kecil saja | Besar + kecil + angka + simbol |
| Tanggal lahir / nama | Bukan data pribadi |
| Sama untuk semua akun | Unik per akun |

**Contoh Kuat:** `S4ya_Suk4#Informatika2026`

---

## Password Manager

### Kenapa perlu?
> Manusia tidak bisa mengingat 50+ password unik!

### Cara kerja:
1. Semua password dienkripsi dalam 1 brankas
2. Cukup ingat **1 master password**
3. Auto-fill saat login

**Bitwarden** (gratis, open source)
**Google Password Manager** (built-in di Chrome)

---

## Aktivitas 1: Generate Password

### Langkah (15 menit):
1. Buka **password generator** (Chrome / Bitwarden)
2. Generate **3 password** masing-masing 16 karakter
3. Simpan ke password manager
4. Cek: ada password yang dipakai ulang?

> **Jangan tulis password asli di LKPD!** Cukup panjang & jenisnya

## 2FA — Lapisan Keamanan Kedua

```
Password (tahu) + 
Kode 2FA (punya) = 
AMAN!
```

### Jenis 2FA:
| Metode | Keamanan |
|---|---|
| SMS | 🟡 Cukup |
| **Authenticator App** | 🟢 **Aman** |
| Hardware Key | 🟢🟢 Paling aman |

---

## Aktivasi 2FA Google

### Langkah (15 menit):
1. Buka **myaccount.google.com**
2. **Security** → **2-Step Verification**
3. Pilih **Authenticator app**
4. Scan QR code
5. Masukkan kode 6 digit
6. 💾 **Backup code** → download!

> **Jangan lewati backup code!** Itu penyelamat jika HP hilang.
