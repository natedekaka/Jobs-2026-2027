## Definisi Sistem Komputer

**Sistem Komputer** = Hardware + Software + Brainware

```
┌────────────────────────────────────────┐
│            SISTEM KOMPUTER             │
├──────────┬──────────┬──────────────────┤
│ HARDWARE │ SOFTWARE │    BRAINWARE     │
│ (Fisik)  │ (Program)│   (Pengguna)     │
└──────────┴──────────┴──────────────────┘
```

---

## Komponen Komputer

![bg right:45% 90%](https://upload.wikimedia.org/wikipedia/commons/thumb/4/4e/Computer_system_bus.svg/800px-Computer_system_bus.svg.png)

### Empat Fungsi Utama:
1. **Input** – Menerima data
2. **Proses** – Mengolah data
3. **Output** – Menampilkan hasil
4. **Storage** – Menyimpan data

---

## Input Device

Perangkat yang mengirim data ke komputer:

| Perangkat | Fungsi |
|---|---|
| ⌨️ Keyboard | Mengetik |
| 🖱️ Mouse | Navigasi |
| 🎙️ Mic | Suara |
| 📷 Webcam | Video |
| 📄 Scanner | Pindai |

---

## CPU — Otak Komputer

### Central Processing Unit

| Bagian | Fungsi |
|---|---|
| **ALU** | Aritmatika & Logika |
| **Control Unit** | Pengatur Operasi |
| **Register** | Memori Kecepatan Tinggi |

> Semakin cepat CPU, semakin cepat komputer memproses data

---

## Memory & Storage

| Jenis | Karakteristik | Contoh |
|---|---|---|
| **RAM** | Volatile, cepat, sementara | 8 GB DDR4 |
| **ROM** | Non-volatile, booting | BIOS |
| **HDD** | Lambat, besar, murah | 1 TB |
| **SSD** | Cepat, mahal | 256 GB |

---

## Output Device

| Perangkat | Fungsi |
|---|---|
| 🖥️ Monitor | Tampilan visual |
| 🔊 Speaker | Suara |
| 🖨️ Printer | Cetak dokumen |
| 📽️ Proyektor | Tampilan besar |

---

## Analogi Sistem Komputer

| Komputer | Tubuh Manusia |
|---|---|
| Keyboard, Mouse | Mata, Telinga |
| CPU | Otak |
| RAM | Memori jangka pendek |
| Hard Disk | Memori jangka panjang |
| Monitor | Mulut (berbicara) |

---

## Cara Kerja Sederhana

**Contoh: Mengetik huruf 'A' di Word**

```
Keyboard (Input)
    ↓
CPU menerjemahkan kode ASCII 65
    ↓
RAM menyimpan sementara
    ↓
Monitor menampilkan 'A' (Output)
    ↓
Save → Hard Disk (Storage)
```

---

## 3 Hal yang Dipelajari Hari Ini

1. ✅ **Sistem komputer** = Hardware + Software + Brainware
2. ✅ **Empat fungsi utama**: Input → Proses → Output → Storage
3. ✅ **Setiap komponen** memiliki peran spesifik
