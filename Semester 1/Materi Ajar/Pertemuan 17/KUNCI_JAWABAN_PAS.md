## BAGIAN B — ESAI

### Esai 1 — Alur IPO + Von Neumann (8 poin)

| Komponen | Peran | Poin |
|---|---|---|
| **Keyboard (Input)** | Menekan tombol "B" → sinyal dikirim ke CPU | 2 |
| **CPU — Control Unit** | Menerima sinyal, mengontrol aliran data | 1 |
| **CPU — ALU** | Memproses data (tidak terlalu relevan untuk input karakter, tapi disebut) | 1 |
| **RAM (Memori)** | Menyimpan instruksi OS dan karakter "B" sementara | 1 |
| **CPU mengirim ke VGA** | Menginstruksikan kartu grafis untuk menampilkan "B" | 1 |
| **Monitor (Output)** | Menampilkan huruf "B" di layar | 2 |

**Alur:** Keyboard (I) → CPU (Fetch → Decode → Execute) → RAM → VGA → Monitor (O)

### Esai 4 — Pengolahan Data (8 poin)

**(a) 3 Masalah Kualitas Data (3 poin — 1 per masalah)**
| Masalah | Jenis |
|---|---|
| "Tujuhpuluh" bukan angka (teks) | Format / tipe data salah |
| "-10" di luar range nilai (0–100) | Invalid / outlier |
| "Andi" muncul 2× | Duplicate |

**(b) Teknik Cleansing (3 poin — 1 per teknik)**
| Masalah | Teknik |
|---|---|
| "Tujuhpuluh" → konversi ke 70 | Koreksi manual atau Find & Replace |
| "-10" → hapus atau koreksi | Data Validation / Filter → hapus |
| Duplikat Andi → hapus 1 baris | Remove Duplicates |

**(c) Dampak GIGO (2 poin)**
- Rata-rata nilai salah (karena "Tujuhpuluh" tidak terhitung, -10 ikut dihitung)
- Rangkap Andi → perhitungan dobel
- Keputusan berdasarkan data salah (misal: siswa remedial padahal tidak)
