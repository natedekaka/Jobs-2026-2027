## 1. Sistem Komputer (Pert 1–4)

| Komponen | Fungsi |
|---|---|
| **CPU** | ALU (hitung) + CU (kontrol) + Register |
| **RAM** | Memori sementara — program & data jalan |
| **ROM** | Firmware / BIOS |
| **Storage** | HDD/SSD — simpan permanen |

**Siklus CPU:** Fetch → Decode → Execute
**Model Von Neumann:** Program & data di memori yang sama

## 5. Pengolahan Data (Pert 14–15)

**GIGO:** Garbage In → Garbage Out

**Jenis masalah data:**
- Format (tanggal campur)
- Missing (kosong)
- Duplicate (ganda)
- Invalid (-5, 30-02-2009)

**Cleansing:** Remove Duplicates, Find & Replace, Filter
