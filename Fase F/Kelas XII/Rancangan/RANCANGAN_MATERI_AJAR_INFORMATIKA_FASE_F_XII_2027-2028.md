## Detail Pertemuan — Semester 1

### Algoritma Sorting (Pert 1–5)

| Pert | Materi | Kegiatan Inti |
|---|---|---|
| **1** | **Konsep Sorting & Bubble Sort** | Konsep pengurutan data, simulasi unplugged Bubble Sort dengan kartu, implementasi Python, visualisasi langkah |
| **2** | **Selection Sort & Insertion Sort** | Simulasi Selection & Insertion Sort, implementasi Python, perbandingan jumlah langkah |
| **3** | **Merge Sort & Quick Sort** | Konsep Divide & Conquer pada sorting, Merge Sort rekursif, Quick Sort dengan pivot, implementasi Python |
| **4** | **Kompleksitas Waktu (Big O)** | Notasi Big O, O(n²) vs O(n log n), pengukuran waktu eksekusi Python, analisis grafik |
| **5** | **Linear Search & Binary Search** | Konsep pencarian, Linear Search vs Binary Search (syarat data terurut), implementasi Python, perbandingan efisiensi |

**PTS Pert 6:** Sorting & Searching

### Struktur Data & OOP (Pert 7–12)

| Pert | Materi | Kegiatan Inti |
|---|---|---|
| **7** | **Linked List** | Konsep node & pointer, singly linked list, implementasi Python (tambah, hapus, cari) |
| **8** | **Stack & Queue** | Konsep LIFO (Stack) dan FIFO (Queue), implementasi Python, contoh: undo/redo, antrian printer |
| **9** | **Aplikasi Struktur Data** | Studi kasus: browser history (stack), antrian server (queue), manajemen playlist (linked list) |
| **10** | **Pengantar OOP** | Class & Object, attribute & method, constructor `__init__`, contoh: class Mahasiswa, class Buku |
| **11** | **Inheritance & Encapsulation** | Pewarisan class, override method, private/public attribute, property decorator |
| **12** | **Polymorphism & Studi Kasus OOP** | Polymorphism, abstract class, studi kasus: sistem perpustakaan / manajemen sekolah |

**PAS Pert 13–15:** Review, ujian tulis, portofolio

## Detail Pertemuan — Semester 2

### Basis Data (Pert 1–4)

| Pert | Materi | Kegiatan Inti |
|---|---|---|
| **1** | **Pengenalan Basis Data & DBMS** | Konsep DBMS, tabel, record, field; perbedaan file vs database; SQLite, DDL (CREATE, ALTER, DROP) |
| **2** | **SQL DML — SELECT, INSERT, UPDATE, DELETE** | Query dasar, SELECT dengan WHERE, ORDER BY, LIMIT; INSERT, UPDATE, DELETE |
| **3** | **JOIN & Relasi Antar Tabel** | Inner Join, Left Join, foreign key; relasi 1-to-1, 1-to-many, many-to-many |
| **4** | **SQLite dengan Python** | Koneksi Python + SQLite, eksekusi query dari Python, studi kasus: database nilai sekolah |

**PTS Pert 5:** Basis Data & SQL

### Proyek Capstone (Pert 6–13)

| Pert | Materi | Kegiatan Inti |
|---|---|---|
| **6** | **Analisis Kebutuhan Proyek** | Pembentukan kelompok, brainstorming ide, analisis kebutuhan pengguna, user story |
