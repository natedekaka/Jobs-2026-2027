## 1. Data Cleaning

| Masalah | Cek | Solusi |
|---|---|---|
| Kosong | `=ISBLANK()` | Isi rata-rata |
| Duplikat | `COUNTIF>1` | Hapus |
| Nilai > 100 | Filter | Koreksi |

---

## 2. Statistik Dasar

| Rumus | Fungsi |
|---|---|
| `=AVERAGE(range)` | Rata-rata |
| `=MAX(range)` | Tertinggi |
| `=MIN(range)` | Terendah |
| `=COUNTIF(range,"≥75")` | Jumlah lulus |
| `=MEDIAN(range)` | Median |

---

## 3. Pivot Table

Rangkum data dalam hitungan detik!

**Langkah:**
1. Data → Pivot table
2. **Rows**: Kelas
3. **Values**: Rata-rata Nilai
4. Selesai! ✅
