## Apa Itu Engineering Process?

**Proses Rekayasa** = langkah terstruktur untuk membuat produk digital

### Analogi: Membangun Rumah

| Rumah | Aplikasi |
|---|---|
| Arsitek | **Design** |
| Tukang | **Implementation** |
| QC | **Testing** |
| Serah terima | **Deployment** |
| Perbaikan | **Maintenance** |

---

## SDLC

**S**oftware **D**evelopment **L**ife **C**ycle

> Siklus hidup pengembangan perangkat lunak

7 tahapan yang harus dilalui setiap produk digital!

---

## 7 Tahapan SDLC

```
1. Planning    → Menentukan tujuan & jadwal
2. Analysis    → Menggali kebutuhan pengguna
3. Design      → Merancang tampilan & arsitektur
4. Implementation → Coding!
5. Testing     → Mencari bug
6. Deployment  → Rilis ke pengguna
7. Maintenance → Perbaikan & update
```

---

## Planning — Perencanaan

"Apa yang ingin kita buat?"

| Output | Contoh |
|---|---|
| Tujuan aplikasi | "Aplikasi presensi siswa" |
| Target pengguna | Siswa & guru SMAN 6 |
| Timeline | 3 bulan |
| Anggaran | Rp 50 juta |

---

## Analysis — Analisis Kebutuhan

"Apa yang dibutuhkan pengguna?"

**Teknik:**
- 🗣️ Wawancara
- 👀 Observasi
- 📋 Kuesioner

| Output | Contoh |
|---|---|
| User story | "Sebagai guru, saya ingin melihat rekap presensi" |
| Spesifikasi | Fitur: scan QR, laporan, notifikasi |

---

## Design — Perancangan

"Bagaimana tampilan & alurnya?"

| Output | Contoh |
|---|---|
| Wireframe | Sketsa tampilan |
| Mockup | Desain visual |
| ERD | Struktur database |
| User flow | Alur pengguna |

---

## Implementation — Coding

"Menulis kode program!"

| Teknologi | Contoh |
|---|---|
| Python, JavaScript, PHP, dll. | |
| Database: MySQL, PostgreSQL | |
| Version control: **Git** + GitHub | |

> **Git** = "save point" di dunia coding — bisa kembali ke versi sebelumnya!

---

## Testing — Pengujian

"Mencari bug sebelum digunakan!"

| Jenis Test | Fungsi |
|---|---|
| Unit Test | Uji fungsi terkecil |
| Integration Test | Uji antar komponen |
| UAT | User mencoba langsung |
| Performance | Uji beban & kecepatan |

---

## Deployment — Peluncuran

"Rilis ke pengguna!"

| Cara | Contoh |
|---|---|
| Play Store / App Store | Aplikasi mobile |
| Web server | Website |
| Staging → Production | Uji coba dulu, baru rilis |

---

## Maintenance — Pemeliharaan

"Perbaikan & pengembangan lanjutan!"

| Aktivitas | Contoh |
|---|---|
| Fix bug | Perbaiki error |
| New features | Tambah fitur baru |
| Security patch | Update keamanan |
| Optimization | Percepat loading |

---

## SDLC — Bukan Garis Lurus!

```
Planning → Analysis → Design → Implementation
    ↑                                      |
    |                                      ▼
    +────────── Maintenance ←── Deployment ←── Testing
                         ↕
                   (iterasi terus!)
```

> **S**iklus = bisa **kembali** ke tahap sebelumnya untuk menyempurnakan!
