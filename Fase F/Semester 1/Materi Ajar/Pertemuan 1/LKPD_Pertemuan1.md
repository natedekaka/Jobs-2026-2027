### C. MIND MAP SDLC (Individu — 5 menit)

Buat mind map 7 tahapan SDLC di buku gambar / halaman kosong!

Gunakan format:

```
                  ┌─────────────────┐
                  │      SDLC       │
                  │  (Siklus Hidup  │
                  │  Pengembangan)  │
                  └────────┬────────┘
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
    ┌──────────┐     ┌──────────┐      ┌──────────┐
    │ Planning │     │ Analysis │      │  Design  │
    └──────────┘     └──────────┘      └──────────┘
         ▼                 ▼                 ▼
    ┌──────────────┐  ┌──────────┐   ┌────────────┐
    │Implementation│  │ Testing  │   │ Deployment │
    └──────────────┘  └──────────┘   └────────────┘
                           ▼
                    ┌─────────────┐
                    │ Maintenance │
                    └─────────────┘
```

Tambahkan **deskripsi singkat** setiap tahapan di mind map!
