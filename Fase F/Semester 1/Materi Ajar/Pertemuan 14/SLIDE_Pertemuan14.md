## Apa itu Big Data?

**Data yang sangat besar, cepat, & beragam — tidak bisa diproses alat tradisional.**

| | Data Biasa | Big Data |
|---|---|---|
| Ukuran | MB - GB | TB - PB |
| Kecepatan | Harian | Real-time |
| Alat | Excel | Hadoop, Spark |

---

## 5V Big Data

| V | Arti |
|---|---|
| **V**olume | Besar — 500 jam video/menit di YouTube |
| **V**elocity | Cepat — 6.000 tweet/detik |
| **V**ariety | Beragam — teks, gambar, video |
| **V**eracity | Benar — akurat atau hoax? |
| **V**alue | Nilai — apa manfaatnya? |

## Data Mining?

**Menemukan pola dari data besar.**

### Proses KDD:

```
Selection → Preprocessing → Transformation
    ↓
Interpretasi ← Data Mining
```

---

## Contoh KDD — Siswa Terlambat

| Tahap | Kegiatan |
|---|---|
| **Selection** | Data absensi 1 tahun |
| **Preprocessing** | Hapus hari libur |
| **Transformation** | Kategorikan >15', >30' |
| **Data Mining** | Cari hari terbanyak |
| **Interpretation** | Senin = apel? |

---

## Teknik Data Mining

| Teknik | Tujuan | Contoh |
|---|---|---|
| **Klasifikasi** | Kategori tertentu | Spam filter |
| **Klastering** | Kelompok alami | Segmentasi pelanggan |
| **Asosiasi** | "Jika A maka B" | Market basket |
| **Regresi** | Prediksi angka | Harga rumah |

## Asosiasi — Market Basket
