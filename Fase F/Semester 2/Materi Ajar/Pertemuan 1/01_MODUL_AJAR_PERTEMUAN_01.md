### Inti (170 menit)

#### Memahami (55 menit)

**1. Review Big Data 5V (15 menit)**

| V | Definisi | Contoh S2 |
|---|---|---|
| **Volume** | Ukuran besar — TB, PB | Data BMKG: 10 TB data cuaca |
| **Velocity** | Kecepatan data masuk | Data Gojek: 1 juta transaksi/hari |
| **Variety** | Beragam jenis (teks, gambar, video) | Data media sosial: teks, foto, video |
| **Veracity** | Kepercayaan/keakuratan | Data penduduk vs data survey online |
| **Value** | Nilai/manfaat dari data | Prediksi cuaca untuk pertanian |

**2. Sumber Data Terbuka & Legal (20 menit)**

| Kategori | Definisi | Contoh |
|---|---|---|
| **Open Data** | Data publik yang bisa diakses, digunakan, dibagikan bebas | data.go.id, data.bmkg.go.id |
| **Public Data** | Data publik tapi ada batasan penggunaan | Data BPS, data Kemendikbud |
| **Private Data** | Data milik individu/ organisasi — butuh izin | Data pasien RS, data pelanggan |
| **Illegal Data** | Data yang diperoleh/digunakan melanggar hukum | Data bocor dari peretasan |

**Mengapa Open Data Penting?**
- Transparansi pemerintah
- Inovasi berbasis data
- Riset & pendidikan
- Partisipasi publik

**3. Etika & Legalitas Data (20 menit)**

| Prinsip | Penjelasan |
|---|---|
| **Izin** | Mintalah izin sebelum mengumpulkan/menggunakan data |
| **Tujuan** | Gunakan data sesuai tujuan awal dikumpulkan |
| **Privasi** | Jangan sebarkan data pribadi tanpa izin |
| **Atribusi** | Sebutkan sumber data |
| **Hapus** | Hapus data jika tidak lagi diperlukan |

**Regulasi:**
- UU PDP 2022: hak data pribadi
- UU ITE: ancaman untuk akses ilegal
