## Kunci Jawaban

### Soal 1 — Big Data 5V (contoh)

| V | Definisi | Contoh |
|---|---|---|
| Volume | Data dalam jumlah sangat besar | Google proses 40.000 pencarian/detik |
| Velocity | Kecepatan data masuk & diolah | Gojek: 1 juta transaksi/hari |
| Variety | Keragaman format data | Data Instagram: teks, foto, video, lokasi |
| Veracity | Kualitas & kepercayaan data | Data BPS terverifikasi, data Twitter tidak |
| Value | Nilai/manfaat dari data | Rekomendasi produk di e-commerce |

### Soal 2 — Klasifikasi

| No | Jawaban | Alasan |
|---|---|---|
| 1 | Open Data | Portal resmi pemerintah, lisensi terbuka |
| 2 | Illegal | Data pribadi siswa disebar tanpa izin |
| 3 | Open Data | Kaggle menyediakan dataset publik |
| 4 | Illegal | Hasil peretasan/ilegal |
| 5 | Public Data | Portal publik pemerintah |
| 6 | Illegal | Scraping data pribadi tanpa izin |
| 7 | Open Data | API publik BMKG |
| 8 | Illegal | Menjual data tanpa izin |

### Soal 5 — Diskusi Etika (contoh jawaban)

| Pertanyaan | Contoh Jawaban |
|---|---|
| Scrape Instagram untuk riset? | Tidak boleh tanpa izin, kecuali data publik dan anonymized |
| Data pasien COVID open data? | Data agregat (jumlah kasus) = open data. Data individu (nama, alamat) = private — tidak boleh |
| Kapan data pribadi tanpa izin? | Keadaan darurat (bencana, pandemi) dengan batasan tertentu |
