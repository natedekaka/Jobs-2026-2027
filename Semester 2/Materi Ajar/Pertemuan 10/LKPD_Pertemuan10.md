### C. MEMBACA PSEUDOCODE — WHILE

**Soal 6:** Baca pseudocode berikut — apa outputnya?

```
PROGRAM soal6
    x ← 1
    WHILE x <= 5
        OUTPUT x × x
        x ← x + 1
    ENDWHILE
END
```

Jawab: _________________________________

**Soal 7:** Baca pseudocode berikut — apa output jika input: 3, 5, 2, 0?

```
PROGRAM soal7
    total ← 0
    INPUT x
    WHILE x ≠ 0
        total ← total + x
        INPUT x
    ENDWHILE
    OUTPUT "Total: ", total
END
```
