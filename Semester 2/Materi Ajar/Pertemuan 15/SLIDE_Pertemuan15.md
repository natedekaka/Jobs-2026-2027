## Review — Pseudocode & Flowchart

| Konsep | Pseudocode |
|---|---|
| Input | `INPUT x` |
| Output | `OUTPUT x` |
| IF | `IF ... THEN ... ELSE ... ENDIF` |
| FOR | `FOR i ← 1 TO n` |
| WHILE | `WHILE kondisi` |

> Flowchart: Oval, Persegi, Decision, Jajar Genjang

---

## Review — Python

```
Pseudocode          →   Python
INPUT x             →   x = int(input())
OUTPUT "Halo"       →   print("Halo")
IF x>0 THEN         →   if x > 0:
FOR i←1 TO 5        →   for i in range(1,6):
WHILE x≠0           →   while x != 0:
```

> Pseudocode → Python = translasi langsung!
