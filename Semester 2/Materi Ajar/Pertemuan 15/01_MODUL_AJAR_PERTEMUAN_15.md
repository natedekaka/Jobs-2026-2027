### Inti (70 menit)

#### Sesi 1: Review PAS (20 menit)

**Review cepat seluruh materi S2:**

| Materi | Poin Penting |
|---|---|
| **Array** | Indeks 0, akses acak, array 2D |
| **Stack** | LIFO, push/pop, contoh: undo, browser back |
| **Queue** | FIFO, enqueue/dequeue, contoh: antrean |
| **Sequential Search** | O(n), cek satu per satu |
| **Binary Search** | O(log n), data terurut |
| **Bubble Sort** | Tukar berpasangan, besar mengapung |
| **Insertion Sort** | Sisip ke posisi tepat |
| **Pseudocode** | INPUT, OUTPUT, ←, IF, FOR, WHILE |
| **Flowchart** | Oval (start/end), persegi (proses), decision, jajar genjang (I/O) |
| **Python** | print(), input(), if-elif-else, for/while, list, def |

#### Sesi 2: Proyek Python (45 menit)

**Pilih salah satu proyek berikut:**

**Opsi A — Kalkulator Sederhana**
- Menu: 1.Tambah 2.Kurang 3.Kali 4.Bagi 5.Keluar
- Input dua angka, tampilkan hasil
- Loop sampai user pilih keluar
- Validasi pembagian dengan 0

**Opsi B — Program Catatan Nilai**
- Input data siswa (nama + nilai) sampai user ketik "selesai"
- Tampilkan: rata-rata, tertinggi, terendah
- Tampilkan daftar lulus (≥75) dan remidi
- Urutkan berdasarkan nilai (descending)

**Opsi C — Game Tebak Angka**
- Angka rahasia random 1–100
- Pemain menebak, dapat petunjuk "terlalu besar/kecil"
- Hitung jumlah tebakan
- Riwayat tebakan ditampilkan
- Skor berdasarkan jumlah tebakan (semakin sedikit semakin baik)
