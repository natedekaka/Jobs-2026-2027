## Apa Itu Struktur Data?

**Definisi:** Cara komputer menyusun, menyimpan, dan mengelola data

```
Data → Struktur Data → Algoritma → Solusi
```

| Struktur Data | Prinsip | Analogi |
|---|---|---|
| **Array** | Berurutan + indeks | Loker, daftar belanja |
| **Stack** | LIFO | Tumpukan piring |
| **Queue** | FIFO | Antrian kasir |

---

## Array — Definisi

Array = kumpulan data sejenis, berurutan, dengan indeks

```
Indeks:    0    1    2    3    4
         ┌────┬────┬────┬────┬────┐
Nilai:   │ 85 │ 90 │ 78 │ 92 │ 88 │
         └────┴────┴────┴────┴────┘
```

- `nilai[0]` = 85
- `nilai[3]` = 92
- Indeks SELALU dimulai dari **0**

---

## Array — Karakteristik

| Karakteristik | Artinya |
|---|---|
| **Ukuran tetap** | Kapasitas ditentukan awal |
| **Tipe seragam** | Semua angka ATAU semua teks |
| **Akses acak** | Langsung ke indeks mana pun |
| **Berurutan** | Bersebelahan di memori |

> Array = cara paling sederhana komputer menyimpan data jamak

---

## Contoh Array

| Contoh | Array |
