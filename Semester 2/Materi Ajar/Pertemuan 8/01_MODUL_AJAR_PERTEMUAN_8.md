### Inti (65 menit)

#### Memahami (25 menit)

**1. Pseudocode (12 menit)**
- **Pseudocode** = "pseudo" (palsu/sem jadi) + "code" (kode) — menyerupai bahasa pemrograman tapi lebih sederhana
- **Tidak terikat bahasa pemrograman tertentu** — bisa diterjemahkan ke Python, C++, Java, dll.
- **Notasi dasar:**

| Notasi | Makna | Contoh |
|---|---|---|
| `INPUT` | Membaca input | `INPUT nama` |
| `OUTPUT` | Menampilkan output | `OUTPUT "Halo"` |
| `←` atau `=` | Assignment | `x ← 5` |
| `IF...THEN...ELSE` | Percabangan | `IF x>0 THEN OUTPUT "+"` |
| `FOR...ENDFOR` | Perulangan pasti | `FOR i←1 TO 5` |
| `WHILE...ENDWHILE` | Perulangan kondisi | `WHILE x<10` |

**2. Flowchart (13 menit)**
- **Flowchart** = diagram alir — representasi visual algoritma

| Simbol | Nama | Fungsi |
|---|---|---|
| ⬭ | Terminator | Mulai / Selesai |
| ▭ | Proses | Assignment, operasi |
| ◇ | Decision | Percabangan (Ya/Tidak) |
| ▱ | Input/Output | INPUT/OUTPUT |
| → | Arrow | Arah aliran |
