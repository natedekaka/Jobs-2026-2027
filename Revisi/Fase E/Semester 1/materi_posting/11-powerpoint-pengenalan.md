# PowerPoint untuk Pemula: Membuat Presentasi, Menambah Slide, dan Mengenal Layout

Setelah mahir menulis dokumen di Word, saatnya naik level ke dunia **presentasi** bersama Microsoft PowerPoint. Dengan PowerPoint kamu bisa menyampaikan ide secara visual dan menarik. Simak pengenalan lengkapnya untuk pemula di sini!

## A. Pengenalan PowerPoint

**Microsoft PowerPoint** adalah aplikasi presentasi dari Microsoft Office. Dengan PowerPoint, kamu dapat menggabungkan teks, gambar, grafik, animasi, hingga video dalam satu tayangan slide.

## B. Membuat Presentasi Baru

1. Buka PowerPoint → **New → Blank Presentation**.
2. Atau **New → pilih template** (Theme) yang tersedia.
3. Slide pertama otomatis dibuat sebagai **Title Slide**.

## C. Menambahkan Slide

| Cara | Shortcut |
|---|---|
| Home → New Slide | **Ctrl+M** |
| Klik kanan slide → New Slide | — |
| Enter di thumbnail terakhir | — |

## D. Layout Slide

**Layout** adalah susunan tata letak slide yang sudah ditentukan desainnya:

| Layout | Kegunaan |
|---|---|
| **Title Slide** | Slide judul |
| **Title and Content** | Judul + isi (paling sering dipakai) |
| **Two Content** | Dua kolom konten |
| **Blank** | Kosong, bebas diatur |
| **Comparison** | Perbandingan 2 sisi |
| **Title Only** | Hanya judul |

## E. Slide Sorter View

Lewat menu **View → Slide Sorter**, kamu bisa melihat semua slide sekaligus. Kamu bisa menarik (drag) slide untuk mengurutkan ulang urutannya.

## F. Text Box & Shape

- **Insert → Text Box** — klik dan drag untuk membuat kotak teks.
- **Insert → Shapes** — pilih bentuk seperti Rectangle, Circle, Arrow, dan lainnya.

## G. Latihan

1. Apa shortcut untuk menambah slide baru langsung pada presentasi?
2. Sebutkan 3 layout slide beserta fungsinya!
3. Apa fungsi Slide Sorter View?
4. Bagaimana cara menambahkan Shape di sebuah slide?

## Rangkuman

- Presentasi baru dimulai dari **Blank Presentation** atau **template**.
- Tambah slide melesat dengan shortcut **Ctrl+M**.
- Layout menentukan susunan utama tiap slide.
- **Slide Sorter** memudahkan pengurutan ulang slide.

Setelah mengenal antarmuka PowerPoint, lanjut belajar mendesain slide yang menarik dan profesional!
