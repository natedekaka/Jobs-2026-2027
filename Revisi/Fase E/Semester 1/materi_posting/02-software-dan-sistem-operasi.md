# Software dan Sistem Operasi: Pengertian, Klasifikasi, dan Cara Kerja Komputer

Setelah mengenal perangkat keras, kali ini kita bahas sisi "tak terlihat" yang membuat komputer hidup: **software**. Tanpa software, hardware hanyalah benda mati. Yuk kenali apa itu program, sistem operasi, hingga cara kerja komputer secara menyeluruh!

## A. Pengertian Software

**Software (perangkat lunak)** adalah kumpulan instruksi yang memberitahu hardware apa yang harus dilakukan. Berbeda dengan hardware yang bisa disentuh, software tidak bisa disentuh karena hanya berbentuk data dan kode.

## B. Klasifikasi Software

Software terbagi menjadi tiga jenis utama:

### 1. Sistem Operasi (OS)
Sistem operasi adalah software utama yang mengelola seluruh hardware dan software di komputer. Contohnya:

| OS | Perangkat | Kelebihan |
|---|---|---|
| Windows 11 | PC/Laptop | User friendly, banyak software |
| macOS | MacBook | Stabil, desain premium |
| Linux (Ubuntu) | PC/Laptop | Open source, ringan |
| Android | HP/Tablet | Terbanyak pengguna |
| iOS | iPhone/iPad | Aman, eksklusif Apple |

### 2. Aplikasi (Application Software)
Program yang membantu menyelesaikan tugas spesifik:

| Aplikasi | Kegunaan |
|---|---|
| Microsoft Word | Mengetik dokumen |
| Google Chrome | Browsing internet |
| Zoom | Video conference |
| Canva | Desain grafis |
| Excel | Spreadsheet |

### 3. Utility
Program pendukung yang membantu menjaga sistem:

| Utility | Fungsi |
|---|---|
| Windows Defender | Antivirus |
| File Explorer | Manajemen file |
| Task Manager | Monitor kinerja |
| Disk Cleanup | Bersihkan file sampah |
| CCleaner | Optimasi sistem |

## C. Sistem Operasi yang Paling Populer

1. **Windows:** dominan di PC (±70% pengguna), mudah digunakan.
2. **Android:** OS mobile terbanyak (±70% smartphone dunia).
3. **iOS:** khusus Apple, sistem tertutup tapi aman.
4. **macOS:** khusus Mac, desain premium.

## D. Cara Kerja Komputer

Coba bayangkan saat kamu mengklik ikon aplikasi Word:

1. **User** mengklik ikon aplikasi (misal: Word).
2. OS mengambil data aplikasi dari **storage**.
3. **CPU** memproses instruksi.
4. **RAM** menyimpan data sementara selama aplikasi berjalan.
5. Hasil ditampilkan di **monitor** (output).

## Rangkuman

- **Software** = program, **hardware** = fisik.
- 3 jenis software: **sistem operasi, aplikasi, utility**.
- OS adalah jembatan antara user dan hardware yang mengatur semuanya.

Paham beda software dan sistem operasi adalah kunci memahami dunia digital. Yuk, cek OS di perangkatmu sekarang!
