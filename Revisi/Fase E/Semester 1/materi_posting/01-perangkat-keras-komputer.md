# Mengenal Perangkat Keras Komputer: Input, Proses, Output, dan Storage

Pernahkah kamu bertanya-tanya, apa saja sih komponen fisik yang membuat komputer bisa menyala, mengetik, dan menampilkan gambar? Semua komponen fisik yang bisa kamu lihat dan sentuh itulah yang disebut **perangkat keras** (hardware). Artikel ini membahas lengkap materi perangkat keras komputer untuk Informatika Fase E atau kelas X.

## A. Pengertian Perangkat Keras (Hardware)

**Hardware** adalah komponen fisik komputer yang bisa dilihat dan disentuh. Keyboard yang kamu ketik, mouse yang kamu geser, hingga CPU yang mengolah data di dalam casing, semuanya termasuk hardware. Hardware dikelompokkan berdasarkan fungsinya dalam skema komputer.

## B. Skema Komputer: Input – Proses – Output – Storage

Komputer bekerja melalui empat fungsi utama. Pahami skema ini karena menjadi fondasi seluruh pemahaman tentang komputer:

| Fungsi | Contoh | Kegunaan |
|---|---|---|
| **INPUT** | Keyboard, Mouse, Scanner, Mikrofon, Webcam | Memasukkan data ke komputer |
| **PROSES** | CPU (Processor), Chipset, GPU | Mengolah data |
| **OUTPUT** | Monitor, Speaker, Printer, Proyektor | Menampilkan hasil olahan |
| **STORAGE** | Harddisk (HDD/SSD), Flashdisk, DVD | Menyimpan data permanen |

Alur singkatnya: kamu mengetik lewat **keyboard** (input) → data diolah **CPU** (proses) → hasilnya tampil di **monitor** (output) → lalu disimpan di **harddisk** (storage).

## C. CPU — Otak Komputer

**CPU (Central Processing Unit)** adalah komponen utama yang memproses seluruh instruksi. CPU terdiri atas tiga bagian penting:

- **ALU (Arithmetic Logic Unit):** mengerjakan operasi matematika dan logika (penjumlahan, perbandingan, dsb).
- **Control Unit:** mengatur aliran data dan mengoordinasikan semua komponen.
- **Register:** memori sementara berkapasitas kecil di dalam CPU yang mempercepat pengolahan.

## D. Jenis-Jenis Perangkat Keras

### Perangkat Input
| Perangkat | Fungsi |
|---|---|
| Keyboard | Mengetik teks/angka |
| Mouse | Menggerakkan kursor |
| Scanner | Memindai dokumen ke digital |
| Mikrofon | Merekam suara |
| Webcam | Merekam video |

### Perangkat Output
| Perangkat | Fungsi |
|---|---|
| Monitor | Menampilkan visual |
| Speaker | Mengeluarkan suara |
| Printer | Mencetak ke kertas |
| Proyektor | Menampilkan ke layar besar |

### Perangkat Penyimpanan (Storage)
| Perangkat | Kapasitas | Kecepatan |
|---|---|---|
| HDD | 500GB – 2TB | Lambat |
| SSD | 128GB – 1TB | Cepat |
| Flashdisk | 8GB – 256GB | Sedang |
| DVD | 4.7GB | Lambat |

## Rangkuman

- Hardware = komponen fisik komputer yang bisa dilihat dan disentuh.
- Komputer memiliki 4 fungsi utama: *Input, Proses, Output, Storage*.
- CPU adalah otak komputer yang menjalankan instruksi.
- HDD lambat tapi kapasitas besar; SSD lebih cepat dan ringan.
