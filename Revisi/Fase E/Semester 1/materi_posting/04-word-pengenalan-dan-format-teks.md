# Microsoft Word untuk Pemula: Bagian Jendela Word dan Format Teks Lengkap

Ingin membuat surat, laporan, atau makalah yang rapi dan profesional? **Microsoft Word** adalah aplikasi pengolah kata paling populer untuk urusan itu. Artikel ini mengupas pengenalannya, bagian-bagian jendela Word, sampai format teks dasar yang wajib kamu kuasai.

## A. Pengenalan Microsoft Word

**Microsoft Word** adalah aplikasi pengolah kata dari paket Microsoft Office. Word digunakan untuk membuat surat, laporan, makalah, undangan, dan berbagai dokumen lainnya. Kuasai Word, semua tugas tulisan jadi mudah!

## B. Bagian-Bagian Jendela Word

| Bagian | Fungsi |
|---|---|
| **Title Bar** | Menampilkan nama file dan aplikasi |
| **Quick Access Toolbar** | Tombol cepat (Save, Undo, Redo) |
| **Ribbon (Tab)** | Menu berdasarkan kategori (Home, Insert, Layout) |
| **Ruler** | Mengatur margin dan indentasi |
| **Document Area** | Tempat mengetik naskah |
| **Status Bar** | Info halaman, word count, zoom |
| **Scroll Bar** | Menggulung halaman ke atas/bawah |

Kenali tiap bagiannya supaya kamu paham tempat kerja di Word.

## C. Format Teks Dasar

| Format | Tombol | Shortcut |
|---|---|---|
| **Bold (tebal)** | B | Ctrl+B |
| *Italic* (miring) | I | Ctrl+I |
| <u>Underline</u> (garis bawah) | U | Ctrl+U |
| ~~Strikethrough~~ (coret) | abc | — |
| Subscript (X₂) | X₂ | Ctrl+= |
| Superscript (X²) | X₂ | Ctrl+Shift++ |

## D. Pengaturan Font

- **Font:** pilih jenis huruf (Times New Roman, Arial, Calibri).
- **Font Size:** ukuran huruf (12pt untuk dokumen formal).
- **Font Color:** warna huruf.
- **Highlight:** warna latar belakang teks.

## E. Latihan

1. Sebutkan 3 bagian dari jendela Word.
2. Apa shortcut untuk **Bold**? Bagaimana dengan *Italic*?
3. Font apa yang biasa digunakan untuk dokumen formal?
4. Apa fungsi Quick Access Toolbar?

## Rangkuman

- Word adalah aplikasi pengolah kata serbaguna.
- Kenali bagian jendela Word agar cepat beradaptasi.
- Format teks dasar: **Bold, Italic, Underline, Font, Size**.
- Shortcut Ctrl+B/I/U mempercepat ketikan.

Format teks adalah dasar dari semua dokumen. Setelah ini, lanjut belajar alignment dan daftar di Word!
