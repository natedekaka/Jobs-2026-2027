# Menyisipkan dan Mengedit Gambar di Word: Wrap Text, Crop, sampai Hapus Background

Dokumen yang berisi teks saja kadang membosankan. Dengan menambahkan **gambar**, dokumenmu jadi lebih menarik dan informatif. Di artikel ini kamu akan belajar cara menyisipkan gambar hingga mengeditnya seperti profesional di Microsoft Word!

## A. Menyisipkan Gambar di Word

Gambar membuat dokumen lebih menarik dan informatif. Ada 4 cara menyisipkan gambar:

1. **Insert → Pictures → This Device** — pilih file gambar dari komputer.
2. **Insert → Pictures → Stock Images** — gunakan gambar bawaan Office.
3. **Insert → Pictures → Online Pictures** — cari gambar lewat browser (Bing).
4. Salin gambar (Ctrl+C) lalu tempel (Ctrl+V) dari sumber lain.

## B. Mengatur Posisi Teks dan Gambar (Wrap Text)

**Wrap Text** mengatur posisi teks terhadap gambar:

| Mode | Efek |
|---|---|
| **In Line with Text** | Gambar seperti karakter teks |
| **Square** | Teks mengelilingi gambar (persegi) |
| **Tight** | Teks mengelilingi bentuk gambar |
| **Through** | Teks mengisi ruang kosong gambar |
| **Top and Bottom** | Teks di atas dan bawah gambar |
| **Behind Text** | Gambar di belakang teks (watermark) |
| **In Front of Text** | Gambar di depan teks |

## C. Alat Pengeditan Gambar (Picture Tools)

Saat gambar dipilih, tab **Format** akan muncul dengan berbagai alat:

- **Corrections:** atur Brightness & Contrast.
- **Color:** atur Saturation, Tone, dan Recolor.
- **Artistic Effects:** efek cat, pensil, watercolor.
- **Remove Background:** hilangkan latar belakang gambar.
- **Crop:** memotong gambar.
- **Compress Pictures:** memperkecil ukuran file.

## D. Mengatur Ukuran Gambar

- Seret **handle sudut** (pertahankan proporsi gambar).
- Atau isi **Format → Size → Height/Width** secara manual.
- Aktifkan **lock aspect ratio** agar gambar tidak terdistorsi.

## Rangkuman

- Gambar disisipkan melalui **Insert → Pictures**.
- **Wrap Text** mengatur posisi teks terhadap gambar.
- **Picture Tools** untuk edit: crop, hapus background, efek, dan kompresi.
- Jaga ukuran dan posisi gambar agar dokumen tidak terlihat pecah.

Kini dokumenmu bisa lebih hidup dengan gambar yang tertata rapi. Lanjut belajar layout halaman di pertemuan berikutnya!
