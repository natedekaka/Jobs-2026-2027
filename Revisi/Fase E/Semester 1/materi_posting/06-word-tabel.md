# Cara Membuat dan Merapikan Tabel di Microsoft Word (Lengkap)

Untuk menyajikan data dalam bentuk baris dan kolom, **tabel** adalah jawabannya. Baik untuk jadwal pelajaran, daftar nilai, maupun data penelitian, tabel membuat informasi terlihat rapi dan mudah dibandingkan. Yuk pelajari cara membuat dan memformat tabel di Word!

## A. Membuat Tabel di Word

**Tabel** digunakan untuk menyajikan data dalam baris dan kolom. Di Word, tabel bisa dibuat dengan 3 cara:

1. Klik **Insert → Table**.
2. Seret kursor untuk memilih jumlah baris **×** kolom yang diinginkan.
3. Atau pilih **Insert → Table → Insert Table** untuk mengisi jumlah baris/kolom secara manual.
4. Atau gunakan **Insert → Table → Draw Table** untuk menggambar tabel secara manual.

## B. Navigasi dalam Tabel

| Tombol | Fungsi |
|---|---|
| **Tab** | Pindah ke sel berikutnya |
| **Shift+Tab** | Pindah ke sel sebelumnya |
| **Panah berarah** | Pindahkan kursor sesuai arah |
| **Enter** | Menambah baris baru di dalam sel |

## C. Operasi Tabel

| Operasi | Cara |
|---|---|
| **Merge Cells** | Blok sel → klik kanan → Merge Cells (menggabungkan) |
| **Split Cells** | Klik sel → klik kanan → Split Cells (memisahkan) |
| **Insert Row** | Klik kanan → Insert → Insert Rows Above/Below |
| **Delete Row** | Klik kanan → Delete Cells → Delete Entire Row |
| **Shading** | Blok → Table Design → Shading (warna latar sel) |
| **Borders** | Table Design → Borders (garis tepi tabel) |

## D. Format Tabel Profesional

Agar tabel terlihat profesional, ikuti tips berikut:

- Header tabel dibuat **bold** + diberi shading warna.
- Gunakan **border minimal** (hampir 3 garis: di atas header, di bawah header, dan di bawah tabel).
- **Angka** diratakan ke tengah, sementara **teks** diratakan ke kiri.
- Hindari penggunaan merged cells jika tidak diperlukan.

## E. Latihan

1. Buat tabel 4×5 menggunakan Insert Table!
2. Gabungkan 2 sel dengan fitur Merge Cells!
3. Berikan shading biru pada header tabelmu!
4. Apa perbedaan dari Merge Cells dan Split Cells?

## Rangkuman

- Tabel = susunan **baris × kolom**.
- Buat tabel lewat **Insert → Table**.
- **Merge** = menggabungkan, **Split** = memisahkan.
- **Shading** = warna latar, **Borders** = garis tepi.

Sekarang kamu bisa membuat tabel yang rapi dan indah. Lanjut ke materi gambar di Word!
