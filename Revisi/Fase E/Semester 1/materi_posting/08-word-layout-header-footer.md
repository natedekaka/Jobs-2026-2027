# Mengatur Layout Halaman di Word: Margin, Orientasi, Header/Footer, dan Nomor Halaman

Dokumen yang bagus tidak hanya isinya, tapi juga **tampilan halamannya**. Kemampuan mengatur *layout* halaman — mulai dari margin, orientasi, hingga nomor halaman — adalah keahlian penting agar dokumenmu terlihat profesional. Ini langkahnya!

## A. Layout Halaman

**Layout** mengatur tampilan halaman secara keseluruhan, termasuk margin, orientasi, kolom, dan elemen lain.

## B. Margin

| Margin | Ukuran | Kegunaan |
|---|---|---|
| **Normal** | 2,54 cm (kanan, kiri, atas, bawah) | Standar |
| **Narrow** | 1,27 cm | Menghemat kertas |
| **Moderate** | 1,91 cm | Kompromi |
| **Wide** | 2,54 cm (atas: 3,81 cm) | Dokumen formal |
| **Custom** | Sesuai kebutuhan | Kebutuhan khusus |

## C. Orientasi Halaman

- **Portrait:** vertikal — dokumen biasa, makalah, laporan.
- **Landscape:** horizontal — tabel, gambar lebar, brosur.

## D. Columns (Kolom)

- **1 kolom:** dokumen biasa.
- **2 kolom:** artikel koran/majalah.
- **3 kolom:** brosur atau pamflet.

## E. Header & Footer

- **Header** = area di atas margin (kop surat, judul bab).
- **Footer** = area di bawah margin (nomor halaman, tanggal).

Cara membuatnya:
1. **Insert → Header/Footer** → pilih template.
2. Ketik teks yang diinginkan.
3. Klik dua kali di luar area untuk selesai.

## F. Page Number (Nomor Halaman)

1. **Insert → Page Number**.
2. Pilih posisi: *Top of Page* / *Bottom of Page*.
3. Pilih format penomoran: **1, 2, 3** / **i, ii, iii** / **-1- -2-**.
4. Atur: **Page Number → Format Page Numbers** untuk mengatur nomor awal.

## G. Latihan

1. Berapa ukuran margin **Normal** di Word?
2. Kapan kita menggunakan orientasi **Landscape**?
3. Apa perbedaan Header dan Footer?
4. Bagaimana cara menambahkan nomor halaman otomatis?

## Rangkuman

- Layout: **margin, orientasi, kolom**.
- **Header = area atas**, **Footer = area bawah**.
- **Page Number** = nomor halaman otomatis yang mengikuti akhir halaman.
