# Teknik Presentasi PowerPoint: Shortcut F5, Presenter View, Audio-Video, dan Tips Sukses

Membuat slide itu satu hal, tapi **menyampaikannya** adalah seni tersendiri. Artikel ini membahas cara memulai presentasi, memanfaatkan Presenter View, tombol navigasi ajaib, sampai tips agar penampilanmu memukau. Catat baik-baik ya!

## A. Memulai Presentasi

| Cara | Shortcut |
|---|---|
| Slide Show → From Beginning | **F5** |
| Slide Show → From Current Slide | **Shift+F5** |
| Presenter View | **Alt+F5** |

## B. Presenter View

Presenter View menampilkan:
- Slide saat ini (**tampilan besar**).
- Slide berikutnya (**tampilan kecil**).
- Catatan presenter.
- Timer berjalan.
- Pointer dan alat menggambar.

Mode ini hanya terlihat di layarmu, audiens tetap melihat fullscreen slide.

## C. Navigasi Saat Presentasi

| Tombol | Fungsi |
|---|---|
| **→ / ↓** | Slide berikutnya |
| **← / ↑** | Slide sebelumnya |
| **G** | Menampilkan layar putih |
| **B** | Menampilkan layar hitam |
| **S** | Stop/Resume presentasi |
| **Esc** | Keluar presentasi |
| **Ctrl+P** | Aktifkan pointer (bisa menggambar) |
| **Ctrl+L** | Pointer jadi laser |
| **Ctrl+A** | Pointer jadi anak panah |

## D. Menyisipkan Audio & Video

1. **Insert → Audio → Audio on My PC** (pilih file MP3/WAV).
2. **Insert → Video → Video on My PC** (pilih file MP4).
3. Atur **Playback → Play**: *Automatically* atau *On Click*.
4. Aktifkan **Play Across Slides** agar audio berlanjut ke slide berikutnya.

## E. Tips Sukses Presentasi

1. Latihan minimal **2×** sebelum presentasi sesungguhnya.
2. Siapkan **cadangan file** di Google Drive.
3. Cek **proyektor & laptop** sebelum mulai.
4. Jaga **kontak mata** dengan audiens.
5. Jangan membaca slide bersama — jelaskan dengan kata-katamu sendiri.

## F. Latihan

1. Shortcut apa untuk memulai presentasi dari awal?
2. Apa kelebihan dari Presenter View?
3. Tombol apa untuk menampilkan layar putih saat presentasi?
4. Sebutkan 3 tips sukses saat presentasi!

## Rangkuman

- Mulai presentasi dengan tombol **F5**.
- **Presenter View** membantu kamu mengontrol jalannya presentasi.
- Tombol **G**, **B**, dan **Esc** adalah teman darurat praktis.
- Latihan dan kontak mata adalah kunci presentasi yang sukses.

Kemampuan presentasi tidak hanya untuk sekolah, tapi juga bekal dunia kerja.
