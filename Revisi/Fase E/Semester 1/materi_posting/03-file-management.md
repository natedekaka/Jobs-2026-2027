# File Management di Komputer: Struktur Folder, Path, Ekstensi File, dan Operasi Dasar

Pernah kesulitan mencari dokumen karena berantakan di mana-mana? Itulah pentingnya **file management**. Dengan manajemen file yang benar, semua dokumen, foto, dan tugas mudah ditemukan dalam beberapa detik. Yuk, pelajari!

## A. Pengertian File Management

**File management** adalah cara mengatur, menyimpan, dan mengelola file di komputer agar mudah ditemukan dan digunakan. Bayangkan komputer sebagai lemari arsip: tanpa label dan rak yang rapi, pasti kacau balau!

## B. Struktur Folder (Directory)

Folder membentuk struktur seperti pohon (hierarki):

```
Drive C: (System)
├── Program Files
├── Users
│   ├── User1
│   │   ├── Documents
│   │   ├── Pictures
│   │   └── Downloads
│   └── Public
└── Windows
```

Semakin ke bawah, folder semakin rinci. Struktur ini membantu sistem menemukan file secara cepat.

## C. Path (Alamat File)

**Path** adalah alamat lengkap file dengan format:

```
Drive:/Folder/Subfolder/NamaFile
```

Contoh: `C:/Users/Budi/Documents/Tugas Informatika/LKPD1.docx`

Dengan path, sistem dan manusia tahu persis di mana file berada.

## D. Ekstensi File

Ekstensi menunjukkan jenis file dan aplikasi yang membukanya:

| Ekstensi | Jenis File | Aplikasi |
|---|---|---|
| .docx | Dokumen Word | Word |
| .xlsx | Spreadsheet | Excel |
| .pptx | Presentasi | PowerPoint |
| .pdf | Dokumen portabel | PDF Reader |
| .jpg / .png | Gambar | Photo Viewer |
| .mp4 | Video | Media Player |
| .mp3 | Audio | Music Player |
| .txt | Teks biasa | Notepad |

## E. Operasi Dasar File Management

| Operasi | Shortcut | Cara Lain |
|---|---|---|
| Copy | Ctrl+C | Klik kanan → Copy |
| Cut | Ctrl+X | Klik kanan → Cut |
| Paste | Ctrl+V | Klik kanan → Paste |
| Rename | F2 | Klik lambat 2x |
| Delete | Delete/Del | Klik kanan → Delete |
| New Folder | Ctrl+Shift+N | Klik kanan → New → Folder |

## F. Tips File Management

1. Gunakan nama folder yang jelas (Tugas, Foto, Musik).
2. **Backup** file penting ke cloud (Google Drive, OneDrive).
3. Hapus file tidak perlu secara berkala.
4. Gunakan **search** (Ctrl+F) untuk mencari cepat.
5. Sortir file berdasarkan tanggal/modified untuk tracking perubahan.

## Rangkuman

- File management = cara mengatur file agar rapi dan mudah dicari.
- **Folder = wadah, File = isi.**
- Path = alamat lengkap file.
- Backup secara rutin untuk mencegah data hilang.

Dengan rapi, kerja jadi efisien dari sejak dini. Mulai rapikan folder di laptopmu hari ini!
