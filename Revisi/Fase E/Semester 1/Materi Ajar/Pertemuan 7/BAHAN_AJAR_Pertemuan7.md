### 🧠 Memahami — Membangun Pemahaman Awal

## A. Menyisipkan Gambar di Word
Gambar membuat dokumen lebih menarik dan informatif.

## B. Cara Menyisipkan Gambar
1. Insert → Pictures → This Device (pilih file dari komputer)
2. Insert → Pictures → Stock Images (gambar bawaan Office)
3. Insert → Pictures → Online Pictures (cari dari Bing)
4. Copy (Ctrl+C) → Paste (Ctrl+V) dari sumber lain

## C. Format Gambar

### Wrap Text (pengaturan posisi teks terhadap gambar)
| Mode | Efek |
|---|---|
| **In Line with Text** | Gambar seperti karakter teks |
| **Square** | Teks mengelilingi gambar (persegi) |
| **Tight** | Teks mengelilingi bentuk gambar |
| **Through** | Teks mengisi ruang kosong gambar |
| **Top and Bottom** | Teks di atas dan bawah gambar |
| **Behind Text** | Gambar di belakang teks (watermark) |
| **In Front of Text** | Gambar di depan teks |

### Picture Tools (Format)
- **Corrections:** Brightness, Contrast
- **Color:** Saturation, Tone, Recolor
- **Artistic Effects:** Cat, Pensil, Watercolor
- **Remove Background:** Hapus latar belakang
- **Crop:** Potong gambar
- **Compress Pictures:** Perkecil ukuran file

## D. Mengatur Ukuran Gambar
- Drag handle sudut (pertahankan proporsi)
- Atau: Format → Size → isi Height/Width
- Lock aspect ratio: cegah distorsi
