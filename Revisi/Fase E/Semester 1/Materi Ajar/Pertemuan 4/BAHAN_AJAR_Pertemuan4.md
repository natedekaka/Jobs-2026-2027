## A. Kisah Pemantik 🎬

> **"Pengumuman RT yang Bikin Ngantuk"**
>
> Ketua RT membuat pengumuman kegiatan kerja bakti. Tulisannya rata kiri semua, tanpa judul tebal, tanpa tanda baca yang rapi — satu blok teks panjang. Warga malas membacanya, banyak yang ketinggalan acara! Padahal isi pengumumannya penting.
>
> Lain waktu, pengumuman dibuat ulang dengan judul **tebal**, poin-poin **miring** untuk waktu, dan bagian penting diberi **garis bawah**. Seketika semua warga paham dan datang tepat waktu.
>
> **Pertanyaan pemantik:** Pernahkah kamu membaca teks berantakan dan merasa malas? Apa yang membuat sebuah dokumen terlihat "profesional" dalam 3 detik pertama?

## B. Pengenalan Microsoft Word

**Microsoft Word** adalah aplikasi pengolah kata dari paket Microsoft Office. Word digunakan untuk membuat surat, laporan, makalah, undangan, dan berbagai dokumen tertulis lainnya. Word adalah "mesin ketik digital" yang dilengkapi ribuan fitur.

| Aplikasi | Jenis | Fungsi Utama |
|---|---|---|
| Microsoft Word | Pengolah kata | Membuat dokumen teks |
| Microsoft Excel | Spreadsheet | Mengolah angka/data |
| Microsoft PowerPoint | Presentasi | Membuat slide |
| Google Docs | Pengolah kata (online) | Alternatif Word di cloud |

## C. Bagian-Bagian Jendela Word

| Bagian | Fungsi |
|---|---|
| **Title Bar** | Menampilkan nama file dan aplikasi |
| **Quick Access Toolbar** | Tombol cepat: Save, Undo, Redo |
| **Ribbon (Tab)** | Menu berdasarkan kategori (Home, Insert, Layout) |
| **Ruler** | Mengatur margin dan indentasi |
| **Document Area** | Tempat mengetik naskah |
| **Status Bar** | Info halaman, jumlah kata, zoom |
| **Scroll Bar** | Menggulung halaman ke atas/bawah |

## D. Format Teks Dasar

| Format | Tombol | Shortcut |
|---|---|---|
| **Bold (tebal)** | B | Ctrl+B |
| *Italic* (miring) | I | Ctrl+I |
| <u>Underline</u> (garis bawah) | U | Ctrl+U |
| ~~Strikethrough~~ (coret) | abc | — |
| Subscript (X₂) | X₂ | Ctrl+= |
| Superscript (X²) | X² | Ctrl+Shift++ |

> 💡 **Tips cepat:** Blok teks terlebih dahulu, **baru** tekan shortcut. Misal: blok judul → `Ctrl+B` → langsung tebal.

## E. Pengaturan Font

- **Font:** pilih jenis huruf — *Times New Roman* dan *Arial* untuk dokumen formal, *Calibri* untuk dokumen santai.
- **Font Size:** ukuran huruf — 12pt standar untuk dokumen formal.
- **Font Color:** warna huruf (hitam untuk dokumen resmi).
- **Highlight:** warna latar belakang teks untuk menandai bagian penting.

| Aspek | Dokumen Formal | Dokumen Kreatif |
|---|---|---|
| Font | Times New Roman | Calibri / Comic Sans |
| Size | 12 pt | Bebas (sesuai desain) |
| Warna | Hitam | Berwarna |
| Layout | Rapi, konsisten | Menarik, variatif |

## F. Contoh Soal & Penyelesaian 📝

**Contoh 1:** Sebutkan 3 bagian dari jendela Word beserta fungsinya!
**Jawaban:**
1. **Title Bar** — menampilkan nama file dan aplikasi.
2. **Ribbon** — menu kategori (Home, Insert, Layout).
3. **Document Area** — tempat mengetik naskah.

**Contoh 2:** Apa shortcut untuk menebalkan teks? Bagaimana dengan miring?
**Jawaban:** Bold = **Ctrl+B**, Italic = **Ctrl+I**, dan Underline = **Ctrl+U**.

**Contoh 3:** Font apa yang biasa digunakan untuk dokumen formal dan berapa ukurannya?
**Jawaban:** *Times New Roman* ukuran **12 pt** — standar untuk makalah, surat resmi, dan laporan karena mudah dibaca dan terlihat resmi.

## G. Miskonsepsi yang Sering Terjadi 🚫

| Miskonsepsi | Fakta yang Benar |
|---|---|
| "Shortcut hanya untuk yang sudah mahir" | Shortcut sederhana (Ctrl+B/I/U/S) mempercepat siapa saja sejak pemula |

## H. Tantangan Praktik (Mengaplikasi) 🎯

**Tantangan 1 — Ketik Pengumuman:** Buat dokumen Word "Pengumuman Kerja Bakti". Buat judul **tebal**, nama kegiatan *miring*, dan tanggal **tebal + garis bawah**. Gunakan font Times New Roman 12pt.

**Tantangan 2 — Lomba Shortcut:** Ketik 3 kalimat tentang dirimu. Terapkan: kalimat 1 semua **bold**, kalimat 2 semua *italic*, kalimat 3 dengan 2 kata **highlight** (misal warna kuning). Semua hanya menggunakan shortcut atau tombol Home.

**Tantangan 3 — Restoran Menu:** Buat daftar menu restoran: nama menu **tebal**, harga miring, keterangan "Baru" di-highlight kuning, dan satu kata yang dicoret untuk menu yang sudah habis. Simpan dengan nama `Menu_Restoran_Namamu.docx`.
