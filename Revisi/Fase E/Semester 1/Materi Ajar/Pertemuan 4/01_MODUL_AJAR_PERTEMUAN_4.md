## Langkah Pembelajaran

### Pembukaan (10 menit)

| Kegiatan | Waktu |
|---|---|
| Salam, doa, cek kehadiran | 3 menit |
| Apersepsi: "Siapa yang pernah buat surat/tugas pakai Word? Word itu apa?" | 7 menit |

### Inti (60 menit)

**Memahami (20 menit):**
- **Tampilan Word:** Title bar, Ribbon (Home/Insert/ Layout), Document area, Status bar, Ruler
- **Format teks:** Bold (B/Ctrl+B), Italic (I/Ctrl+I), Underline (U/Ctrl+U), Font, Size, Color — di Ribbon Home → Font
- **Save:** File → Save (Ctrl+S) → pilih folder → ketik nama → pilih .docx/.pdf → Save

**Mengaplikasi (30 menit):**
- **Aktivitas 1 — Mengetik & Format (20 menit):** Buka Word → ketik 3 kalimat tentang diri sendiri → format: judul bold size 14, isi size 12, 1 kalimat italic, 1 kata underline, ganti warna font
- **Aktivitas 2 — Save (10 menit):** Simpan file sebagai .docx (nama: "Perkenalan_Nama") dan export ke .pdf

**Merefleksi (10 menit):**
- Tombol untuk bold? Beda .docx dan .pdf? Skala 1–10?

### Penutup (20 menit)

Rangkuman, kuis lisan (shortcut bold? italic? save?), tugas: ketik 5 kalimat dengan format berbeda
