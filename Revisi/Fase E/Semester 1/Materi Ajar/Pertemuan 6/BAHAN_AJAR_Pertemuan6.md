### 🧠 Memahami — Membangun Pemahaman Awal

## A. Membuat Tabel di Word
Tabel digunakan untuk menyajikan data dalam baris dan kolom.

## B. Cara Membuat Tabel
1. Klik Insert → Table
2. Seret kursor untuk memilih jumlah baris × kolom
3. Atau: Insert → Table → Insert Table (isi manual jumlah baris/kolom)
4. Atau: Insert → Table → Draw Table (gambar manual)

## C. Navigasi dalam Tabel
| Tombol | Fungsi |
|---|---|
| Tab | Pindah ke sel berikutnya |
| Shift+Tab | Pindah ke sel sebelumnya |
| Panah | Pindah arah |
| Enter | Tambah baris baru di dalam sel |

## D. Operasi Tabel

| Operasi | Cara |
|---|---|
| **Merge Cells** | Blok sel → Klik kanan → Merge Cells (gabung) |
| **Split Cells** | Klik sel → Klik kanan → Split Cells (pisah) |
| **Insert Row** | Klik kanan → Insert → Insert Rows Above/Below |
| **Delete Row** | Klik kanan → Delete Cells → Delete Entire Row |
| **Shading** | Blok → Table Design → Shading (warna latar) |
| **Borders** | Table Design → Borders (garis tepi) |

## E. Format Tabel Profesional

### Tips:
- Header tabel bold + shading warna
- Gunakan border minimal (hampir 3 garis: header, bawah header, bawah tabel)
- Rata tengah untuk angka, rata kiri untuk teks
- Hindari merged cells jika tidak perlu

## F. Latihan
1. Buat tabel 4×5 menggunakan Insert Table
2. Gabung 2 sel menggunakan Merge Cells
3. Beri shading biru pada header tabel
4. Apa perbedaan Merge Cells dan Split Cells?

- Tabel = baris × kolom
- Insert → Table untuk membuat
- Merge = gabung, Split = pisah
- Shading = warna latar, Borders = garis
