## B. Mengapa Tabel?

**Tabel** adalah susunan data dalam **baris** (mendatar) dan **kolom** (menurun). Tabel membuat data mudah dibandingkan dan terlihat rapi.

| Data sebagai Kalimat | Data dalam Tabel |
|---|---|
| "Senin pukul 07.00 Matematika dengan Bu Sari, pukul 08.30 Informatika dengan Pak Rudi..." | Baris = jam, kolom = hari, isi = mapel |

| Bagian Tabel | Fungsi |
|---|---|
| **Baris** | Data mendatar |
| **Kolom** | Data menurun |
| **Sel** | Pertemuan baris × kolom (tempat data) |
| **Header** | Baris/kolom pertama sebagai judul data |

---

## C. Cara Membuat Tabel di Word

Ada **3 cara** utama:

1. **Klik Insert → Table** → seret kursor untuk memilih jumlah baris × kolom yang diinginkan.
2. **Insert → Table → Insert Table** → ketik manual jumlah baris dan kolom.
3. **Insert → Table → Draw Table** → gambar tabel secara manual dengan kursor.

> 💡 **Tips cepat:** Untuk tabel besar (misal 10×6), gunakan cara **Insert Table** dan isi angkanya manual agar lebih presisi.

## D. Navigasi dalam Tabel

| Tombol | Fungsi |
|---|---|
| **Tab** | Pindah ke sel berikutnya |
| **Shift+Tab** | Pindah ke sel sebelumnya |
| **Panah berarah** | Memindahkan kursor sesuai arah |
| **Enter** | Menambah baris baru di dalam sel |

---

## E. Operasi pada Tabel

| Operasi | Cara |
|---|---|
| **Merge Cells** | Blok sel → klik kanan → Merge Cells (menggabungkan beberapa sel menjadi satu) |
| **Split Cells** | Klik sel → klik kanan → Split Cells (memisahkan satu sel menjadi beberapa) |
| **Insert Row** | Klik kanan → Insert → Insert Rows Above/Below |
| **Delete Row** | Klik kanan → Delete Cells → Delete Entire Row |
| **Shading** | Blok sel → tab Table Design → Shading (memberi warna latar) |
| **Borders** | tab Table Design → Borders (mengatur garis tepi tabel) |

> 💡 **Kapan memakai Merge?** Saat membuat judul tabel yang membentang beberapa kolom (misal sel "Data Siswa Kelas X" di atas 4 kolom).

## F. Format Tabel Profesional

Agar tabel terlihat rapi dan profesional:

1. **Header** dibuat **bold** + diberi **shading** warna (misal biru muda).
2. Gunakan **border minimal** — sekitar 3 garis utama: di atas header, di bawah header, dan di bawah tabel.
3. **Angka** diratakan ke tengah, **teks** diratakan ke kiri.
4. **Hindari merged cells** yang tidak perlu agar data tetap mudah dibaca.

```
┌──────────────┬──────────────┬──────────────┐
│  Header (bold+shading)    │              │
├──────────────┼──────────────┼──────────────┤
│ Teks (kiri)  │   12 (tengah)│  Teknik Informatika │
└──────────────┴──────────────┴──────────────┘
```

## G. Contoh Soal & Penyelesaian 📝

**Contoh 1:** Sebutkan 3 cara membuat tabel di Word!
**Jawaban:**
1. **Insert → Table** → seret kursor memilih baris × kolom.
2. **Insert → Table → Insert Table** → isi manual jumlah baris/kolom.
3. **Insert → Table → Draw Table** → menggambar manual.

**Contoh 2:** Apa perbedaan Merge Cells dan Split Cells?
**Jawaban:** Merge Cells **menggabungkan** beberapa sel menjadi satu (misal untuk judul tabel), sedangkan Split Cells **memisahkan** satu sel menjadi beberapa sel (misal menambah kolom pada satu sel).

**Contoh 3:** Bagaimana cara memberi warna latar (shading) biru pada header tabel?
**Jawaban:** Blok sel header → tab **Table Design** → klik **Shading** → pilih warna biru. Tambahkan bold pada teks header agar menonjol.

## H. Miskonsepsi yang Sering Terjadi 🚫

| Miskonsepsi | Fakta yang Benar |
|---|---|
| "Tabel dan border harus tebal semua" | Tabel profesional memakai **border minimal** (biasanya 3 garis utama) |
| "Merge Cells sama dengan Split Cells" | Merge = **menggabungkan**; Split = **memisahkan** |
| "Menekan Tab di sel terakhir menutup tabel" | Tab di sel terakhir justru **menambah baris baru** |
| "Angka dan teks harus diratakan sama" | Angka rata **tengah**, teks rata **kiri** agar enak dibaca |
