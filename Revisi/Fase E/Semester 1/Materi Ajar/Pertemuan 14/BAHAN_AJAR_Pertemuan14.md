### 🧠 Memahami — Membangun Pemahaman Awal

## A. Memulai Presentasi
| Cara | Shortcut |
|---|---|
| Slide Show → From Beginning | F5 |
| Slide Show → From Current Slide | Shift+F5 |
| Presenter View | Alt+F5 |

## B. Presenter View
Presenter View menampilkan:
- Slide saat ini (besar)
- Slide berikutnya (kecil)
- Catatan presenter
- Timer
- Pointer dan alat menggambar

## C. Navigasi Saat Presentasi
| Tombol | Fungsi |
|---|---|
| → atau ↓ | Slide berikutnya |
| ← atau ↑ | Slide sebelumnya |
| G | Tampilkan layar putih |
| B | Tampilkan layar hitam |
| S | Stop/Resume presentasi |
| Esc | Keluar presentasi |
| Ctrl+P | Aktifkan pointer (gambar) |
| Ctrl+L | Pointer jadi laser |
| Ctrl+A | Pointer jadi arrow |

## D. Menyisipkan Audio & Video
1. Insert → Audio → Audio on My PC (pilih file MP3/WAV)
2. Insert → Video → Video on My PC (pilih file MP4)
3. Atur: Playback → Start: Automatically / On Click
4. Atur: Play Across Slides (audio lanjut ke slide berikutnya)

## E. Tips Presentasi
1. Latihan minimal 2x sebelum presentasi
2. Siapkan cadangan file di Google Drive
3. Cek projector/laptop sebelum mulai
4. Kontak mata dengan audiens
5. Jangan membaca slide — jelaskan dengan kata sendiri
