## A. Pengertian Perangkat Keras (Hardware)
Hardware adalah komponen fisik komputer yang bisa dilihat dan disentuh. Hardware dikelompokkan berdasarkan fungsinya dalam skema komputer.

## B. Skema Komputer: INPUT – PROSES – OUTPUT – STORAGE

| Fungsi | Contoh | Kegunaan |
|---|---|---|
| **INPUT** | Keyboard, Mouse, Scanner, Mikrofon, Webcam | Memasukkan data ke komputer |
| **PROSES** | CPU (Processor), Chipset, GPU | Mengolah data |
| **OUTPUT** | Monitor, Speaker, Printer, Proyektor | Menampilkan hasil olahan |
| **STORAGE** | Harddisk (HDD/SSD), Flashdisk, DVD | Menyimpan data permanen |

## C. CPU — Otak Komputer
CPU (Central Processing Unit) adalah komponen utama yang memproses instruksi. Komponen CPU:
- **ALU (Arithmetic Logic Unit):** operasi matematika dan logika
- **Control Unit:** mengatur aliran data
- **Register:** memori sementara dalam CPU
