## 4 Komponen Utama Komputer

```
INPUT → PROSES → OUTPUT → STORAGE
```

Data masuk → diolah → hasil → disimpan

---

## Perangkat Input

| Perangkat | Fungsi |
|---|---|
| Keyboard | Mengetik teks/perintah |
| Mouse | Menggerakkan kursor |
| Mikrofon | Merekam suara |
| Scanner | Memindai dokumen |
| Webcam | Merekam gambar/video |

---

## Perangkat Proses

**CPU (Central Processing Unit)** — otak komputer

Semua perhitungan dan pemrosesan data dilakukan di sini.

**Komponen CPU:**
- ALU (Aritmatika & Logika)
- Control Unit
- Register

---

## Perangkat Output

| Perangkat | Fungsi |
|---|---|
| Monitor | Menampilkan gambar |
| Speaker | Mengeluarkan suara |
| Printer | Mencetak ke kertas |
| Proyektor | Menampilkan ke layar besar |

---

## Perangkat Storage

| Perangkat | Kapasitas | Kecepatan |
|---|---|---|
| Hard Disk (HDD) | 500GB-2TB | Lambat |
| SSD | 256GB-1TB | Cepat |
| Flashdisk | 8GB-256GB | Portabel |
| Memory Card | 16GB-512GB | Untuk HP/kamera |
