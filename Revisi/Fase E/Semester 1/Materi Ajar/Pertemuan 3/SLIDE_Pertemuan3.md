---

## Folder vs File

| Folder | File |
|---|---|
| Wadah/container | Isi/dokumen |
| Bisa berisi folder lain | Bisa dibuka dengan program |
| Tidak punya ekstensi | Punya ekstensi (.docx, .jpg) |
| Ikon folder 🗀 | Ikon sesuai jenis |

---

## Ekstensi File

| Ekstensi | Jenis | Program |
|---|---|---|
| .docx | Dokumen Word | Microsoft Word |
| .xlsx | Spreadsheet | Microsoft Excel |
| .pptx | Presentasi | PowerPoint |
| .pdf | Dokumen portable | Adobe Reader |
| .jpg/.png | Gambar | Photos |
| .mp3 | Audio | Music player |
| .mp4 | Video | Video player |

---

## Operasi Dasar File

| Operasi | Cara Cepat | Shortcut |
|---|---|---|
| Copy | Klik kanan → Copy | Ctrl + C |
| Paste | Klik kanan → Paste | Ctrl + V |
| Cut (Pindah) | Klik kanan → Cut | Ctrl + X |
| Rename | Klik kanan → Rename | F2 |
| Delete | Klik kanan → Delete | Delete/Del |
| New Folder | Klik kanan → New → Folder | Ctrl+Shift+N |

---

## File Explorer

**Navigasi:**
- Quick Access (akses cepat)
- This PC (semua drive)
- Search box (cari file)

**Tips:**
- Gunakan search untuk cari cepat
- Group by type untuk lihat per jenis
- Sort by date untuk file terbaru

---

## Flashdisk

| Langkah | Cara |
|---|---|
| Colok | Masukkan ke port USB |
| Buka | Notification → Open folder |
| Aman cabut | Klik kanan flashdisk → Eject |
| Kapasitas | Cek di Properties |

**⚠️ Selalu eject sebelum mencabut!**
