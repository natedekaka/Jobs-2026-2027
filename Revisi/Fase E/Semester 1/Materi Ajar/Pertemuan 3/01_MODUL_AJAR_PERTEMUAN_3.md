## Langkah Pembelajaran

### Pembukaan (10 menit)

| Kegiatan | Waktu |
|---|---|
| Salam, doa, cek kehadiran | 3 menit |
| Apersepsi: "Berapa banyak file di HP kalian? Susah cari foto? —> pentingnya folder rapi" | 7 menit |

### Inti (60 menit)

**Memahami (20 menit):**
- **File vs Folder:** File = berkas (dokumen, gambar). Folder = tempat file. Ikon folder = 📁 amplop.
- **Ekstensi file:** .docx (Word), .jpg (gambar), .pdf (dokumen portable), .mp4 (video), .xlsx (Excel)
- **Operasi dasar:** Copy (Ctrl+C), Paste (Ctrl+V), Cut/Move (Ctrl+X), Rename (F2), Delete (Del)

**Mengaplikasi (30 menit):**
- **Aktivitas 1 — Praktik File Explorer (20 menit):** Buka File Explorer (Win+E) → buat folder "Kelas X-A" di Desktop → di dalamnya buat folder "Tugas" dan "Catatan" → copy file dari Documents → rename → delete
- **Aktivitas 2 — Sortir Ekstensi (10 menit):** Amati folder Downloads — kelompokkan file berdasarkan ekstensi

**Merefleksi (10 menit):**
- Beda file & folder? 3 ekstensi file? Skala 1–10?

### Penutup (20 menit)

Rangkuman, kuis lisan (sebut 1 ekstensi file gambar, 1 ekstensi dokumen), tugas: buat struktur folder rapi di Desktop
