### 🧠 Memahami — Membangun Pemahaman Awal

## A. Mail Merge
Mail Merge adalah fitur untuk membuat banyak dokumen serupa dengan data berbeda (surat undangan, sertifikat, label).

## B. Langkah Mail Merge
1. **Siapkan data:** Buat file Excel dengan kolom: Nama, Alamat, Nilai, dll
2. **Siapkan template:** Dokumen Word dengan teks utama
3. **Mail Merge Wizard:**
   - References → Start Mail Merge → Step by Step Mail Merge Wizard
   - Pilih: Letters
   - Select recipients → Use existing list → pilih file Excel
   - Insert merge fields: klik di posisi → Insert Merge Field → pilih field
   - Preview Results: lihat hasil
   - Finish & Merge: Print atau Edit Individual Documents

## C. Field yang Sering Digunakan
- <<Nama>> — nama penerima
- <<Alamat>> — alamat
- <<Kota>> — kota
- <<Tanggal>> — tanggal surat
- <<Nilai>> — nilai (untuk raport, sertifikat)

## D. Daftar Isi (Table of Contents)
Daftar isi otomatis berdasarkan heading styles.

### Langkah:
1. Beri style Heading 1, Heading 2, Heading 3 pada judul
2. References → Table of Contents → pilih format
3. Jika ada perubahan: Update Table → Update entire table

## E. Update Daftar Isi
Setelah edit dokumen:
- Klik daftar isi → Update Table
- Pilih: Update page numbers only / Update entire table
