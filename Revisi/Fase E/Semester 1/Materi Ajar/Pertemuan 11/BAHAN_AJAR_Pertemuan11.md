### 🧠 Memahami — Membangun Pemahaman Awal

## A. Pengenalan PowerPoint
Microsoft PowerPoint adalah aplikasi presentasi dari Microsoft Office.

## B. Membuat Presentasi Baru
1. Buka PowerPoint → New → Blank Presentation
2. Atau: New → pilih template (Theme)
3. Slide pertama otomatis: Title Slide

## C. Menambahkan Slide
| Cara | Shortcut |
|---|---|
| Home → New Slide | Ctrl+M |
| Klik kanan slide → New Slide | - |
| Enter di thumbnail terakhir | - |

## D. Layout Slide
Layout adalah tata letak slide yang sudah ditentukan:

| Layout | Kegunaan |
|---|---|
| **Title Slide** | Slide judul |
| **Title and Content** | Judul + isi (paling sering) |
| **Two Content** | Dua kolom |
| **Blank** | Kosong, bebas atur |
| **Comparison** | Perbandingan 2 sisi |
| **Title Only** | Hanya judul |

## E. Slide Sorter View
View → Slide Sorter — melihat semua slide sekaligus, drag untuk urutkan ulang.

## F. Text Box & Shape
- Insert → Text Box → klik + drag
- Insert → Shapes → pilih (Rectangle, Circle, Arrow, dll)
