## Perangkat Lunak (Software)

**Software** adalah program yang menjalankan komputer. Tanpa software, hardware tidak berguna.

**3 Jenis Software:**
| Jenis | Contoh |
|---|---|
| Sistem Operasi | Windows, Linux, macOS |
| Aplikasi | Word, Excel, Chrome, Canva |
| Utility | Antivirus, WinRAR, CCleaner |

---

## Sistem Operasi (OS)

OS adalah software utama yang mengelola seluruh sumber daya komputer.

**Fungsi OS:**
- Mengelola file dan folder
- Menjalankan aplikasi
- Mengatur memori dan proses
- Menghubungkan hardware dan software

**Contoh OS populer:** Windows 10/11, Linux (Ubuntu), macOS

---

## Mengenal Windows

| Komponen | Fungsi |
|---|---|
| Desktop | Layar utama |
| Taskbar | Bilah bawah (start, icon, jam) |
| Start Menu | Daftar semua program |
| File Explorer | Mengelola file/folder |
| System Tray | Ikon background (baterai, wifi, volume) |

---

## Membuka & Menutup Program

**Membuka:**
- Start Menu → ketik nama program → Enter
- atau Klik icon di taskbar/desktop

**Menutup:**
- Klik X di pojok kanan atas
- atau Alt + F4
- atau Task Manager → End Task

---

## Task Manager

**Cara buka:** Ctrl + Shift + Esc atau Ctrl + Alt + Del

**Fungsi:**
- Melihat program yang berjalan
- Menutup program yang not responding
- Melihat penggunaan CPU, RAM, disk

---

3. Screenshot hasilnya
