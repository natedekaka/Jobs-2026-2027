## Langkah Pembelajaran

### Pembukaan (10 menit)

| Kegiatan | Waktu |
|---|---|
| Salam, doa, cek kehadiran | 3 menit |
| Apersepsi: "HP kalian bisa jalan karena apa? Hardware-nya? Atau ada yang lain?" | 7 menit |

### Inti (60 menit)

**Memahami (20 menit):**
- **HW vs SW:** Hardware = fisik (monitor, keyboard). Software = program (Windows, Word). Analogi: tubuh vs jiwa.
- **3 jenis software:** OS (Windows/macOS/Linux), Aplikasi (Word/Chrome), Utility (Antivirus/File Explorer)
- **Task Manager (Ctrl+Shift+Esc):** lihat program berjalan, CPU/RAM, tutup program macet

**Mengaplikasi (30 menit):**
- **Aktivitas 1 — Klasifikasi (15 menit):** Kelompokkan: Windows 11, Chrome, Word, Defender, Android, Photoshop, File Explorer, Zoom → OS/Aplikasi/Utility
- **Aktivitas 2 — Task Manager (15 menit):** Buka Task Manager, catat: jumlah proses, %CPU, %RAM. Tutup 1 aplikasi lewat Task Manager

**Merefleksi (10 menit):**
- Beda HW & SW? OS komputer sekolah? Skala 1–10?

### Penutup (20 menit)

Rangkuman, kuis lisan (sebut 1 OS, 1 aplikasi, 1 utility), tugas: cari 1 software baru di HP/komputer
