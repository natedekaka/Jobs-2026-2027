## A. Pengenalan Microsoft Excel
Microsoft Excel adalah aplikasi spreadsheet untuk mengolah data angka, membuat tabel, grafik, dan analisis data.

## B. Bagian-Bagian Excel
| Bagian | Fungsi |
|---|---|
| **Workbook** | File Excel (.xlsx) |
| **Worksheet** | Lembar kerja (Sheet1, Sheet2) |
| **Cell** | Pertemuan baris dan kolom (A1, B2) |
| **Range** | Kumpulan cell (A1:A10) |
| **Formula Bar** | Tempat menulis rumus |
| **Ribbon** | Menu Home, Insert, Formulas, Data |

## C. Cell dan Range
- **Cell address:** Kolom + Baris (A1 = kolom A baris 1)
- **Range:** A1:D10 = cell A1 sampai D10
- **Active Cell:** cell yang sedang dipilih

## D. Memasukkan Data
| Tipe Data | Contoh |
|---|---|
| Teks | Nama, alamat, kategori |
| Angka | Harga, jumlah, nilai |
| Tanggal | 1/1/2025, Jan-25 |
| Rumus | =A1+B1, =SUM(A1:A10) |

## E. Format Cell
- Number: angka biasa, persen, mata uang
- Alignment: rata kiri/kanan/tengah
- Font: jenis, ukuran, warna, bold
- Border: garis tepi cell
- Fill: warna latar cell

## F. Auto Fill
Ketik 1 dan 2 di 2 cell → blok → drag ke bawah → otomatis 3,4,5,6...
Berguna untuk membuat nomor urut, deret tanggal, deret angka.
