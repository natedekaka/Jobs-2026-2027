# KUNCI JAWABAN – PERTEMUAN 1 (S2)
## Pengenalan Microsoft Excel
*Mengacu pada Panduan Mapel 2025; INFORMATIKA Fase D-F — pendekatan Pembelajaran Mendalam (Memahami → Mengaplikasi → Merefleksi)*


### 🧠 Memahami — Kunci Jawaban

**Aktivitas 1:** 
- 3 bagian Ribbon: Home, Insert, Page Layout
- Cell C5 (kolom C baris 5)
- Range A1:D10

**Aktivitas 2 — Tabel:**
| No | Nama Barang | Harga | Jumlah |
|---|---|---|---|
| 1 | Buku | Rp5.000 | 10 |
| 2 | Pensil | Rp2.000 | 5 |
| 3 | Penghapus | Rp3.000 | 3 |
Auto Fill: ketik 1 dan 2, drag ke bawah

**Aktivitas 3 — Format Cell:**
- Harga: Format Cells → Currency → Rp
- Jumlah: Format Cells → Number → 0 desimal
- Header: bold (Ctrl+B) + font color biru
