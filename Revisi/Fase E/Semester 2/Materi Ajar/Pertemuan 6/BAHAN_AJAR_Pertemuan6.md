### 🧠 Memahami — Membangun Pemahaman Awal

## A. Browser
Browser adalah aplikasi untuk mengakses internet (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

## B. Fitur Browser
| Fitur | Shortcut | Fungsi |
|---|---|---|
| Tab | Ctrl+T | Buka halaman baru |
| Bookmark | Ctrl+D | Simpan halaman favorit |
| History | Ctrl+H | Riwayat browsing |
| Download | Ctrl+J | Lihat file diunduh |
| Incognito | Ctrl+Shift+N | Mode pribadi |
| Zoom | Ctrl++/- | Perbesar/kecil |
| Print | Ctrl+P | Cetak halaman |

## C. Search Engine
Search engine adalah mesin pencari (Google, Bing, Yahoo, DuckDuckGo).

### Operator Pencarian Lanjutan:
| Operator | Fungsi | Contoh |
|---|---|---|
| `site:` | Cari di domain tertentu | site:kemendikbud.go.id pendidikan |
| `filetype:` | Cari jenis file | filetype:pdf informatika |
| `"kata"` | Cari frasa persis | "informatika SMA" |
| `-kata` | Kecualikan kata | resep -ayam |
| `..` | Rentang angka | HP 2jt..5jt |
| `intitle:` | Kata di judul | intitle:pendidikan |

## D. Mengevaluasi Sumber Informasi
| Kriteria | Trustworthy | Skeptis |
|---|---|---|
| Domain | .go.id, .ac.id, .org | .com, .info |
| Penulis | Jelas identitas | Anonim |
| Tanggal | Terbaru | Tidak ada tahun |
| Referensi | Ada sumber | Klaim tanpa bukti |
