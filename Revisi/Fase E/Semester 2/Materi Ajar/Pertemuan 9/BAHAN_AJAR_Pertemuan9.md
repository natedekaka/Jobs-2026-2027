## B. Apa Itu Canva? 🎨

**Canva** adalah aplikasi desain grafis **online** yang mudah digunakan, cocok untuk pemula. Berbasis *drag and drop* (seret dan letakkan), sehingga tanpa keahlian desain profesional pun kamu bisa membuat poster, infografis, presentasi, dan konten media sosial. Tersedia di `canva.com` dan aplikasi Android/iOS.

| Istilah | Arti |
|---|---|
| **Canvas** | Area kerja/kanvas tempat kamu mendesain |
| **Template** | Desain siap pakai yang tinggal diedit |
| **Element** | Komponen desain: foto, ikon, shape, garis |
| **Upload** | Mengunggah file/gambar sendiri |
| **Download/Export** | Menyimpan desain ke perangkat |

> 💡 **Kelebihan Canva:** ribuan template gratis, mudah dipakai bersama tim, dan hasilnya bisa diekspor dalam berbagai format.

## D. Membuat Desain Baru Langkah demi Langkah 🛠️

### D.1 Memulai
1. Buka `canva.com` → klik **Sign up** → daftar menggunakan akun Google.
2. Klik tombol **"Create a design"** (atau pilih template di halaman utama).
3. Pilih ukuran kanvas sesuai kebutuhan:
   - **Instagram Post** (1080×1080 px)
   - **Poster A4** (29,7 × 21 cm)
   - **Presentasi** (1920×1080 px)
   - **Story** (1080×1920 px)

### D.2 Mengisi Kanvas
1. **Text:** klik Text → pilih Heading/Subheading/Body → ketik → atur font, ukuran, warna.
2. **Elements:** klik Elements → ketik kata kunci (mis. "education", "technology") → seret hasilnya ke kanvas.
3. **Upload:** klik Upload → pilih gambar dari perangkat → seret ke kanvas.
4. **Background:** klik latar kanvas → pilih warna/gradasi/gambar.

### D.3 Mengatur Elemen
- Klik elemen untuk memilih → muncul pengaturan posisi, ukuran, rotasi, dan urutan.
- Gunakan menu **Position** untuk membawa elemen ke depan/belakang (bring forward / send backward).
- Tekan **Ctrl+D** untuk menggandakan elemen.

## E. Mengekspor (Download) Desain 📤

Setelah selesai:
1. Klik tombol **Share** → **Download**.
2. Pilih format:
   - **PNG** — kualitas gambar tinggi, bagus untuk konten medsos.
   - **JPG** — ukuran file kecil, cocok untuk foto/upload cepat.
   - **PDF** — terbaik untuk cetak atau dokumen resmi.
   - **MP4/GIF** — untuk animasi (versi tertentu).
3. Atur ukuran file (bila perlu) → klik **Download**.

> ⚠️ **Perhatikan lisensi:** gunakan elemen berlabel "Free" untuk penggunaan umum. Beberapa elemen berbayar (Pro) perlu izin jika dipakai untuk komersial.

## F. Contoh Soal & Penyelesaian 📝

**Contoh 1:** Bagaimana cara memulai membuat desain di Canva?
**Pembahasan:** Login di canva.com → klik "Create a design" → pilih ukuran/template → mulai mengedit kanvas. Bisa juga langsung memilih template yang tersedia.

**Contoh 2:** Sebutkan 3 fitur utama Canva beserta fungsinya.
**Pembahasan:** (1) Template — desain siap pakai; (2) Elements — foto/ikon/bentuk; (3) Upload — memasukkan gambar sendiri. Bisa juga menyebut Text, Background, atau Magic Design.

**Contoh 3:** Format apa yang paling cocok untuk mencetak poster?
**Pembahasan:** **PDF** — karena menjaga kualitas cetak dan tata letak, tidak pecah saat dicetak.

**Contoh 4:** Apa fungsi Magic Design?
**Pembahasan:** Magic Design membuat desain otomatis berdasarkan teks/deskripsi yang kamu ketik, sehingga cepat menghasilkan draft awal yang tinggal disempurnakan.
