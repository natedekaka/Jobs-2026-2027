## 🧠 MEMAHAMI — Membangun Pemahaman Awal

### A. Mengapa Fondasi Ini Penting?
Sebelum mengajarkan siswa, guru harus menguasai alatnya. Seorang guru yang lancar mencontohkan langsung lebih dipercaya dan menghemat waktu mengajar. Tiga keterampilan inti Kelas X:
1. **Word** — dokumen, surat massal (mail merge), laporan resmi.
2. **PowerPoint** — presentasi yang komunikatif, bukan sekadar tempel teks.
3. **Canva** — desain komunikasi visual (poster, infografis, konten medsos).

### B. Konsep-Konsep Utama

**1) Mengetik Efisien (Shortcut Inti)**
| Shortcut | Fungsi |
|---|---|
| `Ctrl+B / I / U` | Bold / italic / underline |
| `Ctrl+E / L / R` | Rata tengah / kiri / kanan |
| `Ctrl+Enter` | Pindah halaman |
| `F4` | Ulangi aksi terakhir (sangat berguna) |
| `Ctrl+A` → `F9` | Refresh tabel/daftar isi di Word |
| `Alt` | Menampilkan kunci akses menu di ribbon |

**2) Teori Desain CRAP** (dari *Non-Designer's Design Book*)
- **C**ontrast (kontras) — bedakan judul vs body.
- **Repetition** (repetisi) — ulangi gaya untuk konsistensi.
- **Alignment** (sejajar) — setiap elemen punya posisi yang disengaja.
- **Proximity** (kedekatan) — kelompokkan yang berkaitan.

## 🔧 MENGAPLIKASI — Praktik & Penerapan

### Praktik 1 — Word: Dokumen dengan Daftar Isi Otomatis
**Langkah 1—Gunakan Format Judul:**
1. Ketik judul bab → sorot → pilih **Heading 1** (bukan sekadar bold).
2. Untuk subbab gunakan **Heading 2** dan **Heading 3**.
3. Gunakan **Styles** agar dokumen konsisten dan mudah diubah.

**Langkah 2—Buat Daftar Isi Otomatis:**
1. Klik di awal dokumen → tab **References** → **Table of Contents**.
2. Pilih gaya → daftar isi muncul otomatis.
3. Jika isi berubah: `Ctrl+A` → `F9` → *Update entire table*.

**Langkah 3—Mail Merge (Surat Massal):**
1. Siapkan file data (Excel/CSV) berisi kolom: Nama, Kelas, dll.
2. Di Word → **Mailings** → **Start Mail Merge** → **Letters**.
3. Klik **Select Recipients** → *Use an Existing List* → pilih file.
4. Ketik surat, lalu klik **Insert Merge Field** untuk nama, kelas, dst.
5. **Preview Results** → **Finish & Merge** → *Edit Individual Documents*.

> Contoh data dummy tersedia di `magang/DATA_DUMMY_NILAI_PTS.csv`.

### Praktik 2 — PowerPoint: Slide di Luar Template Bawaan
1. Buka presentasi baru → **View** → **Slide Master** → atur judul, footer, posisi sekaligus.
2. Buat 15 slide, **1 ide per slide**.
3. Terapkan CRAP: kontras font (1 judul + 1 body), repetisi gaya, sejajar, dekatkan yang berkaitan.
4. Animasi minimal: gunakan **Appear** hanya untuk menampilkan poin bertahap.
5. Transisi konsisten (mis. semua *fade*).

**Kriteria slide baik:**
- Bisa dipahami pembaca hanya dari gambar + 1 kalimat.
- Tidak penuh bullet.
- Teks ≥ 24pt.

### Praktik 3 — Canva: Infografis & Poster
1. Buat desain berukuran target (A3 untuk poster, spesifik untuk infografis).
2. Gunakan **grid** untuk menyejajarkan elemen (CRAP: alignment).
3. Jaga palet warna 2–3 warna + 2 font.
4. Manfaatkan **Magic Switch** (ubah ukuran sekali untuk semua varian) dan **Magic Eraser** (hapus background).
