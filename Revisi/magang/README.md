## Cara Bertahap (Alur Belajar)
1. **Mulai** dari `PETA_JALAN_MAGANG_GURU_INFORMATIKA.md`
2. Kerjakan **1 tahap** urut; tiap tahap = **Rencana Harian + bahan latihan**
3. **Satu tahap = satu produk bukti** (jangan lanjut tanpa bukti)
4. **Ajarkan = kuasai**: setiap minggu ajarkan 1 konsep baru ke orang lain
5. **Ulangan terjadwal**: setiap 2 tahap, ulangi simulasi tahap sebelumnya tanpa catatan
