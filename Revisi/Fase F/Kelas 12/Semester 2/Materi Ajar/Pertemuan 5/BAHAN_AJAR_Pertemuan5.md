> **"Laporan Sepuluh Halaman, Nol Pembaca"**
>
> Kelompok Sari menulis laporan setebal 20 halaman penuh kalimat bertele-tele. Ketika guru menanyakan hasilnya, tidak ada yang ingat isinya. Guru menunjukkan sebuah infografis 1 halaman dari kelompok lain yang ringkas, berwarna, dan langsung jelas. Sari sadar: *"Bukan banyaknya halaman, tapi kejelasan pesannya."*
>
> Mereka menyusun ulang laporan dengan struktur jelas (bab pendahuluan, metode, hasil, pembahasan, kesimpulan) dan merangkum temuan utama dalam satu infografis Canva yang menarik. Sekarang laporan mereka dibaca, dan infografisnya dipajang di mading sekolah.

## B. Konsep Inti: Laporan dan Infografis Saling Melengkapi

**Laporan** adalah dokumen lengkap yang menjadi bukti dan arsip ilmiah proyek. **Infografis** adalah ringkasan visual satu halaman untuk menyampaikan pesan utama dengan cepat. Keduanya harus **konsisten** — infografis adalah "resume" dari laporan.

| Aspek | Laporan | Infografis |
|---|---|---|
| Tujuan | Dokumentasi lengkap | Komunikasi cepat |
| Panjang | 10–15 halaman | 1 halaman |
| Isi | Teks + tabel + grafik | Angka besar + grafik + ikon |
| Format | Word/Google Docs (.docx/.pdf) | Canva (.png/.pdf) |
| Pembaca | Guru, juri | Publik luas, mading, media sosial |

> 💡 **Ingat:** Laporan membuktikan pekerjaanmu; infografis membuat orang peduli.

## C. Struktur Laporan Proyek

### Cover
Judul, logo sekolah, nama anggota, kelas, tanggal.

### Bab 1: Pendahuluan
- Latar belakang masalah (100–150 kata).
- Tujuan (SMART, 3 poin).
- Manfaat (2–3 poin).

### Bab 2: Metode Penelitian
- Jenis data: kuantitatif/kualitatif.
- Sumber data: primer (survei) / sekunder.
- Teknik: survei, observasi, wawancara.
- Responden: jumlah + kriteria.

### Bab 3: Hasil dan Pembahasan
- Ringkasan data mentah (tabel).
- Pivot Table + Chart (minimal 3 analisis).
- Interpretasi tiap analisis.
- Insight utama.

### Bab 4: Kesimpulan dan Saran
- Kesimpulan menjawab tujuan proyek.
- Saran untuk pihak terkait (sekolah, guru, siswa).

### Lampiran
- Data mentah, screenshot, foto kegiatan.

> 💡 **Tips kolaborasi:** gunakan **Google Docs** agar semua anggota bisa menulis bagian yang berbeda secara bersamaan dan guru bisa memberi komentar langsung.

## D. Desain Infografis di Canva

### D.1 Ukuran dan Langkah Dasar
- Ukuran: **1080×1920 px** (IG Story) atau **1080×1080 px** (IG Feed).
1. Canva → *Create a Design* → Infografis (atau custom 1080×1920).
2. Pilih template minimalis (cari "Infografis Data").
3. Masukkan:
   - Judul besar (font 48–60 pt).
   - 3–4 data penting dengan angka besar (font 36–48 pt).
   - Grafik (screenshot dari Excel) atau elemen Canva.
   - Ikon terkait (Canva Elements).
4. Warna konsisten: maksimal 2–3 warna.
5. Font: maksimal 2 jenis.

### D.2 Prinsip Desain
| Prinsip | Penjelasan | Contoh |
|---|---|---|
| Hierarki | Informasi terpenting paling menonjol | Judul + angka besar di atas |
| Kontras | Teks terbaca jelas dari latar | Warna gelap di latar terang |
| Konsistensi | Warna & font seragam | 1 template untuk semua slide/poster |
| Ruang putih | Jangan penuhi semua area | Beri jarak antar elemen |
| Satu pesan | Fokus pada 1 ide utama | 3–4 data terpenting saja |

### D.3 Template Infografis (Contoh)

```
+-------------------------------------------+
| 📊 FAKTA MEMBACA SISWA SMAN 6 CIMAHI      |
+-------------------------------------------+
|                                            |
|  3,5 buku/bulan       45% suka Fiksi      |
|  Rata-rata kelas      Genre terpopuler    |
|                                            |
|  [Chart: Buku per Kelas] [Pie: Genre]     |
|                                            |
|  80% membaca <1 jam/hari 20% ≥2 jam/hari  |
|                                            |
|  "Tingkatkan literasi, tingkatkan masa     |
|   depan!"                                  |
+-------------------------------------------+
```

## F. Contoh Soal & Penyelesaian 📝

**Soal 1:** Sebutkan isi Bab 3 (Hasil dan Pembahasan) dalam laporan proyek.
**Pembahasan:** Bab 3 memuat ringkasan data mentah (tabel), Pivot Table + chart (minimal 3 analisis), interpretasi tiap analisis, dan insight utama yang menjawab tujuan proyek.

**Soal 2:** Mengapa infografis sebaiknya memuat maksimal 3–4 data penting dengan angka besar?
**Pembahasan:** Infografis dibaca dalam hitungan detik; terlalu banyak data membuat pesan utama hilang. Angka besar dan terbatas membantu pembaca langsung menangkap temuan terpenting, seperti rata-rata, persentase tertinggi, atau tren utama.

**Soal 3:** Sebutkan 3 prinsip desain Canva dan beri contoh penerapannya.
**Pembahasan:** (1) Hierarki — judul dan angka besar paling menonjol; (2) Kontras — teks gelap di latar terang agar terbaca; (3) Konsistensi — maksimal 2–3 warna dan 2 jenis font agar tampilan rapi dan profesional.

## G. Kesalahan Umum dalam Desain & Laporan 🚫

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Laporan menyalin template tanpa mengubah isi | Tidak sesuai data proyek | Tulis ulang sesuai temuan kelompok |
| Infografis penuh teks kecil | Tidak terbaca dari jauh | Angka besar, teks minimal |
| Terlalu banyak warna/font | Terlihat norak, tidak profesional | Batasi 2–3 warna & 2 font |
| Grafik tanpa judul/interpretasi | Pembaca bingung | Beri judul grafik + interpretasi |
| Laporan dikerjakan satu orang saja | Beban menumpuk, hasil tidak lengkap | Kolaborasi via Google Docs |

## I. Rangkuman Kunci 🔑

1. Laporan = bukti lengkap; infografis = ringkasan visual yang komunikatif.
2. Struktur laporan: cover, Bab 1 (pendahuluan), Bab 2 (metode), Bab 3 (hasil & pembahasan), Bab 4 (kesimpulan), lampiran.
3. Gunakan Google Docs agar kolaborasi anggota mudah.

6. Laporan dan infografis harus konsisten dengan temuan proyek.
