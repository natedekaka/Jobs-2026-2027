## A. Tujuan Pembelajaran
Setelah mempelajari materi ini, siswa mampu:
1. Mengidentifikasi tren teknologi terkini (AI, Big Data, Cloud, IoT, Cybersecurity)
2. Menjelaskan peluang karier di bidang teknologi
3. Menyusun rencana pengembangan skill digital

## B. 5 Tren Teknologi Digital Saat Ini
**1. AI (Artificial Intelligence) dan Machine Learning**
- AI bisa: menulis, mendesain, membuat kode, menganalisis data
- Contoh: ChatGPT, Canva AI, GitHub Copilot
- Peluang karier: AI Engineer, Machine Learning Engineer, Prompt Engineer

**2. Big Data dan Data Analytics**
- Data → keputusan bisnis
- Tools: Excel, SQL, Tableau, Python
- Profesi: Data Analyst, Data Scientist, Business Intelligence Analyst

**3. Cloud Computing**
- Simpan data di internet tidak di hardisk
- Layanan: Google Drive, iCloud, AWS, Google Cloud, Azure
- Kerja remote/online dari mana saja
- Profesi: Cloud Engineer, DevOps Engineer

**4. Cybersecurity (Keamanan Siber)**
- Semakin banyak data digital, semakin besar risiko bocor
- Contoh: kebocoran data Tokopedia, Facebook, BPJS
- Profesi: Security Analyst, Ethical Hacker, Security Engineer

**5. IoT (Internet of Things)**
- Perangkat sehari-hari terhubung internet
- Contoh: smart watch, smart home, kulkas pintar
- Profesi: IoT Developer, Embedded System Engineer

## C. Skill yang Wajib Dimiliki di Era Digital
**Hard Skills (Teknis):**
1. Microsoft Office (Excel, Word, PPT) — wajib untuk semua profesi
2. Data Analysis — baca data, buat keputusan
3. Desain Grafis — Canva, Photoshop dasar
4. Basic Coding — Python, HTML, SQL
5. Digital Marketing — media sosial, SEO, content creation

**Soft Skills (Non-teknis):**
1. Critical Thinking — analisis masalah, cari solusi
2. Problem Solving — selesaikan masalah sistematis
3. Communication — tulis dan bicara efektif
4. Collaboration — kerja tim, manajemen proyek
5. Adaptability — belajar teknologi baru cepat

## D. Tips Sukses di Era Digital
1. **Terus belajar:** ikuti perkembangan teknologi (1 jam/hari baca artikel/tutorial)
2. **Bangun personal branding:**
   - LinkedIn profile profesional
   - Portofolio online (Canva/GitHub/Google Sites)
3. **Networking:** ikut seminar, workshop, komunitas IT
4. **Portofolio > Ijazah:** tunjukkan hasil karya, bukan hanya nilai rapor
5. **Jaga etika digital:** reputasi online penting untuk karier
