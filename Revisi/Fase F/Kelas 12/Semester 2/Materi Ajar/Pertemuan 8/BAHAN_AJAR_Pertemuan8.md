## A. Kisah Pemantik 🎬

> **"Satu File yang Terhapus"**
>
> Sehari sebelum pengumpulan, laptop kelompok Wulan rusak dan file Excel proyek hilang. Panik! Beruntung mereka pernah menyimpan salinan di Google Drive dua hari sebelumnya, jadi kerugiannya hanya beberapa jam kerja. Wulan menghela napas: *"Kalau tidak ada backup, proyek kami musnah total."*
>
> Sejak itu, setiap selesai mengerjakan, mereka langsung mengunggah ke folder kelompok dengan nama file yang rapi. Saat finalisasi, semua komponen utuh, terorganisir, dan siap presentasi.
>
> **Pertanyaan pemantik:**
> 1. Apa yang akan terjadi jika file proyekmu rusak tanpa backup?
> 2. Mengapa penamaan file yang konsisten penting dalam kerja kelompok?
> 3. Apa saja yang perlu dicek sebelum produk dinyatakan "final"?

---

## B. Konsep Inti: Finalisasi = QC + Backup + Organisasi

**Finalisasi** adalah tahap memastikan semua komponen proyek **lengkap, rapi, dan aman**. Tiga pilar finalisasi: **quality control** (periksa kualitas), **backup** (amankan salinan), dan **organisasi file** (rapikan penamaan & folder).

| Istilah | Arti | Contoh |
|---|---|---|
| **Finalisasi** | Menyelesaikan & memvalidasi produk akhir | Semua file siap kumpul |
| **Quality control (QC)** | Pemeriksaan kualitas produk | Cek isi, format, kelengkapan |
| **Backup** | Salinan cadangan data | Google Drive, flashdisk |
| **Naming convention** | Aturan penamaan file yang konsisten | Proyek_K1_Excel.xlsx |
| **Dashboard** | Tampilan ringkas data dalam 1 halaman | Ringkasan analisis proyek |

> 💡 **Ingat:** Tidak ada pekerjaan yang "selesai" sebelum diverifikasi. File tanpa backup sama dengan pekerjaan yang bisa hilang kapan saja.

## D. Detail Finalisasi Tiap Komponen

### D.1 Excel (.xlsx)
- Sheet "Data_Mentah" — data asli dari Google Form.
- Sheet "Data_Bersih" — hasil cleaning.
- Sheet "Analisis" — 3 Pivot + 3 Chart + interpretasi.
- Sheet "Dashboard" (opsional) — ringkasan 1 halaman.
- Format rapi: font konsisten, freeze pane, tanpa merged cells.

### D.2 Laporan (.docx/.pdf)

| Bab | Isi | Selesai | Cek |
|---|---|---|---|
| Cover | Judul, anggota, logo | ☐ | ☐ |
| Bab 1 | Latar belakang, tujuan, manfaat | ☐ | ☐ |
| Bab 2 | Metode, responden, teknik | ☐ | ☐ |
| Bab 3 | Hasil: Pivot, Chart, interpretasi | ☐ | ☐ |
| Bab 4 | Kesimpulan dan saran | ☐ | ☐ |
| Lampiran | Data mentah, screenshot, foto | ☐ | ☐ |

### D.3 Infografis (.png/.pdf)
- Ukuran 1080×1920 px.
- Judul jelas.
- 3–4 data penting (angka besar).
- Grafik screenshot dari Excel.
- Ikon relevan, font terbaca.

### D.4 Slide Presentasi (.pptx/.pdf)
- 10 slide: cover, latar, tujuan, metode, hasil 1–3, kesimpulan, saran, penutup.
- Warna dan font konsisten.
- Visual (chart, infografis) lebih dominan daripada teks.
- Siap dibawakan.

## E. Naming Convention dan Backup Google Drive

### E.1 Aturan Penamaan File
```
Proyek_Kelompok1_Excel.xlsx
Proyek_Kelompok1_Laporan.pdf
Proyek_Kelompok1_Infografis.png
Proyek_Kelompok1_Slide.pptx
```
Nama file konsisten memudahkan guru menemukan dan menilai, serta mencegah "file_akhir2_final_beneran.docx".

### E.2 Langkah Backup
1. Buat folder: **"Proyek Akhir Informatika – [Nama Kelompok]"**.
2. Buat subfolder: Excel, Laporan, Desain, Slide.
3. Unggah semua file final.
4. Share link dengan guru.
5. Pastikan semua anggota punya akses dan salinan lokal.

> 💡 **Aturan backup:** minimal 2 tempat berbeda (Google Drive + flashdisk/laptop) untuk setiap file penting.

## F. Contoh Soal & Penyelesaian 📝

**Soal 1:** Sebutkan 4 komponen wajib proyek akhir dan format filenya masing-masing.
**Pembahasan:** (1) Excel analisis (.xlsx), (2) laporan proyek (.docx/.pdf), (3) infografis Canva (.png/.pdf), (4) slide presentasi (.pptx/.pdf).

**Soal 2:** Mengapa penamaan file yang konsisten penting dalam proyek kelompok?
**Pembahasan:** Nama file konsisten (mis. Proyek_Kelompok1_Laporan.pdf) memudahkan identifikasi, menghindari kebingungan antar anggota, mencegah versi ganda yang tidak jelas, dan memudahkan guru menilai. Tanpa aturan penamaan, muncul file seperti "fix_final2.docx" yang membingungkan.

**Soal 3:** Kelompokmu lupa membuat backup dan laptop rusak. Apa yang harus dilakukan?
**Pembahasan:** Periksa salinan yang mungkin ada: Google Drive, email, flashdisk, atau perangkat anggota lain. Jika semua hilang, laporkan jujur ke guru dan kerjakan ulang secepat mungkin dengan waktu tersisa. Karena itu, aturan backup (minimal 2 tempat) wajib diterapkan sejak awal.
