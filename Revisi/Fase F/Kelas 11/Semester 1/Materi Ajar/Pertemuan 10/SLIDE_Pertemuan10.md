## IF-ELSE Sederhana

```
IF kondisi THEN
    perintah_benar
ELSE
    perintah_salah
ENDIF
```

---

## Contoh: Nilai Huruf

```
INPUT nilai
IF nilai >= 85 THEN OUTPUT "A"
ELSE IF nilai >= 70 THEN OUTPUT "B"
ELSE IF nilai >= 55 THEN OUTPUT "C"
ELSE OUTPUT "D"
ENDIF
```

---

## Contoh: Diskon Bertingkat

≥ 500.000 → diskon 20%
≥ 250.000 → diskon 10%
< 250.000 → diskon 0%
