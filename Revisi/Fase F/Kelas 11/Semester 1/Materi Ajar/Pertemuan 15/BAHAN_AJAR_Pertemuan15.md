### 🔧 Mengaplikasi — Praktik & Penerapan

## C. Soal Review

**Soal 1: Flowchart**
Buat flowchart untuk: Input jam dan menit, konversi ke total menit. (jam * 60 + menit)

**Soal 2: Flowchart Percabangan**
Buat flowchart: Input 3 bilangan -> output yang terbesar.

**Soal 3: Flowchart Perulangan**
Buat flowchart: Cetak bilangan kelipatan 3 dari 3 sampai 30.

**Soal 4: Pseudocode**
Tulis pseudocode: Input nilai -> predikat A >= 85, B >= 70, C >= 55, D < 55.

**Soal 5: Excel**
Data 10 siswa: NIS, Nama, Tgl Lahir
Buat kolom: Usia (DATEDIF), Email (LOWER + @), Status (IF usia >= 16, "SMA", "Belum")

## D. Strategi Ujian PAS
1. Flowchart: kuasai 3 simbol utama (proses, I/O, decision)
2. Pseudocode: hafal struktur IF-ELSE-ENDIF, FOR, WHILE
3. Excel: kuasai LEFT, RIGHT, MID, LEN, DATEDIF, CONCATENATE
4. Waktu: kerjakan mudah dulu
5. Praktek: gambar flowchart dengan rapi
