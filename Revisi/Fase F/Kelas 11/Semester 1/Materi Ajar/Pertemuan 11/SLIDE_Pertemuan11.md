## FOR Loop

```
FOR i ← 1 TO 10
    OUTPUT i
ENDFOR
```

✅ Jumlah ulangan sudah diketahui

---

## WHILE Loop

```
WHILE kondisi
    perintah
ENDWHILE
```

✅ Jumlah ulangan belum diketahui
✅ Berhenti saat kondisi false

---

## Contoh: Tabel Perkalian

```
FOR i ← 1 TO 3
    FOR j ← 1 TO 3
        OUTPUT i * j
    ENDFOR
ENDFOR
```

Nested loop = loop di dalam loop
