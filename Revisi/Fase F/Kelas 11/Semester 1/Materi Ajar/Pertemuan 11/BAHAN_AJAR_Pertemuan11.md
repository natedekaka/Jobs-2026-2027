## A. Perulangan FOR
Digunakan jika jumlah perulangan sudah diketahui.

```
FOR i = 1 TO 5
    OUTPUT i
ENDFOR
```

### B. Perulangan WHILE
Digunakan jika perulangan berdasarkan kondisi.

```
i = 1
WHILE i <= 5
    OUTPUT i
    i = i + 1
ENDWHILE
```

### C. FOR vs WHILE
| Aspek | FOR | WHILE |
|---|---|---|
| Jumlah iterasi | Diketahui | Tergantung kondisi |
| Counter otomatis | Ya | Manual |
| Risiko infinite | Rendah | Tinggi |

### D. Contoh Pseudocode Perulangan
**Menjumlah 1-5:**
```
START
    jumlah = 0
    FOR i = 1 TO 5
        jumlah = jumlah + i
    ENDFOR
    OUTPUT jumlah
END
```
Hasil: 15
