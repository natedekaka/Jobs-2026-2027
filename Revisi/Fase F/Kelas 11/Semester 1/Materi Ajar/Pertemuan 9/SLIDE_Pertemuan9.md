## Keyword Pseudocode

| Keyword | Fungsi |
|---|---|
| INPUT | Membaca data |
| OUTPUT | Menampilkan hasil |
| IF/ELSE | Percabangan |
| FOR/WHILE | Perulangan |
| ← atau = | Assignment |

---

## Contoh

**Flowchart (luas segitiga):**
(lihat gambar)

**Pseudocode:**
```
INPUT alas, tinggi
luas ← 0.5 * alas * tinggi
OUTPUT luas
```
