## A. Apa Itu Pseudocode?
Pseudocode adalah notasi algoritma yang mirip dengan bahasa manusia tetapi terstruktur seperti kode program. Pseudocode tidak bisa dijalankan langsung di komputer — fungsinya untuk merencanakan logika sebelum coding.

### B. Struktur Pseudocode
```
START
    INPUT variabel
    PROSES (rumus/logika)
    OUTPUT hasil
END
```

### C. Kata Kunci Pseudocode
| Kata | Fungsi |
|---|---|
| INPUT | Membaca data |
| OUTPUT | Menampilkan hasil |
| IF...THEN...ELSE | Percabangan |
| FOR / WHILE | Perulangan |
| SET / = | Assignment |

### D. Contoh Pseudocode
**Menghitung Luas Persegi Panjang:**
```
START
    INPUT panjang
    INPUT lebar
    luas = panjang * lebar
    OUTPUT luas
END
```

### E. Pseudocode vs Flowchart vs Kode

| Aspek | Flowchart | Pseudocode | Kode (Python) |
|---|---|---|---|
| Visual | ✅ | ❌ | ❌ |
| Siap di-coding | ❌ | ✅ | ✅ |
| Butuh software | Tidak | Tidak | Ya |

**Flowchart → Pseudocode → Python**
Ini adalah pipeline standar dalam membuat program.
