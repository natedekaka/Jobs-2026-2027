## Percabangan = Decision

Ketika ada **dua pilihan** berdasarkan kondisi

Simbol: ◇ Belah Ketupat
Output: Ya / Tidak (True / False)

---

## Contoh: Ganjil/Genap

```
Input angka
    ↓
angka % 2 == 0 ? ──Ya──→ Output "Genap"
    ↓
  Tidak
    ↓
Output "Ganjil"
```

---

## Contoh: Login

```
Input user & pass
    ↓
user="admin" AND pass="1234" ?
  ├─Ya──→ "Login berhasil"
  └─Tidak → "Login gagal"
```
