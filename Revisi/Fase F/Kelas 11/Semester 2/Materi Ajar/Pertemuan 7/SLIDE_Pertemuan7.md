## Fungsi = Blok Kode Reusable

```python
def sapa():
    print("Halo!")
    
sapa()  # panggil
```

---

## Dengan Parameter

```python
def sapa(nama):
    print(f"Halo, {nama}!")

sapa("Andi")
sapa("Budi")
```

---

## Return Value

```python
def tambah(a, b):
    return a + b

hasil = tambah(5, 3)
print(hasil)  # 8
```
