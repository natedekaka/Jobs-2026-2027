## IF Sederhana

```python
    print("Lulus")
```

---

## IF-ELSE

```python
if nilai >= 75:
    print("Lulus")
else:
    print("Tidak lulus")
```

---

## IF-ELIF-ELSE

```python
if nilai >= 85:
    print("A")
elif nilai >= 70:
    print("B")
elif nilai >= 55:
    print("C")
else:
    print("D")
```
