2. Menerapkan praktik keamanan digital (password, 2FA)
3. Mengenali phishing dan cara menghindarinya
4. Melakukan backup data sederhana

## B. Mengapa Keamanan Digital Penting?
- Data pribadi ada di HP, laptop, cloud
- Ancaman nyata: kebocoran data, peretasan, penipuan
- Contoh: data 279 juta penduduk Indonesia bocor (2021)

## C. Jenis Ancaman
**1. Malware**
| Jenis | Cara | Dampak |
|-------|------|--------|
| Virus | Menempel di file | Rusak file |
| Worm | Menyebar sendiri | Habiskan bandwidth |
| Trojan | Menyamar program baik | Curi data |
| Ransomware | Kunci file, minta tebusan | File hilang |
| Spyware | Memata-matai | Curi password |

**2. Phishing — Penipuan Mengelabui**
Pelaku berpura-pura jadi pihak terpercaya untuk curi data.

**Ciri Phishing:**
- Email dari domain aneh meniru bank/sekolah
- Ada link "Klik untuk verifikasi"
- Ancaman urgent: "Akun akan ditutup!"
- Minta data pribadi: password, PIN
- Tata bahasa aneh, banyak typo

**3. Hacking — Peretasan**
Akses ilegal ke sistem/akun orang lain.
Motif: curi data, rusak website, crypto mining

## D. Praktik Keamanan
**1. Password Kuat**
| Lemah | Kuat |
|-------|------|
| 123456 | G4L4ngS3nja!2025 |
| password | Kucing_Belajar_Python! |
| tanggal lahir | Saya_Lulus_SMA_2026# |

Aturan: min 12 karakter, kombinasi huruf besar+kecil+angka+simbol, jangan pakai data pribadi, beda tiap akun.

**2. 2FA (2 Factor Authentication)**
Password + kode OTP / sidik jari / face ID.
Aktifkan di: Email, IG, WA, Google, akun bank.

**3. Backup Data**
- Backup file penting: Google Drive, OneDrive
- Aturan 3-2-1: 3 salinan, 2 media, 1 off-site
