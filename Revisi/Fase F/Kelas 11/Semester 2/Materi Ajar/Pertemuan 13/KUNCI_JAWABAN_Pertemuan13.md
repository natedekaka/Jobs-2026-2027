### 🧠 Memahami — Kunci Jawaban

### A. Kunci Aktivitas 1 — Jenis Ancaman
Virus: Menempel di file -> menyebar saat file dijalankan
Worm: Menyebar sendiri melalui jaringan
Trojan: Menyamar sebagai program baik
Ransomware: Mengunci file dan meminta tebusan
Phishing: Penipuan untuk mencuri data/login


### B. Kunci Aktivitas 2 — Email Phishing
Ciri: 1) Domain tidak resmi (bit.ly bukan bni.co.id)
2) Ancaman/urgensi (akan ditutup)
3) Minta klik link/memberikan data pribadi


### 🔧 Mengaplikasi — Kunci Jawaban

### C. Kunci Aktivitas 3 — Password Kuat
Min 12 karakter, kombinasi huruf besar+kecil+angka+simbol
Contoh: "Saya$ukaPython2025!" (cek di passwordmonster.com)


### D. Kunci Aktivitas 4 — 2FA & Keamanan Akun
2FA: myaccount.google.com > Security > 2-Step Verification
Ganti password tiap 3-6 bulan. Jangan gunakan password yang sama untuk banyak akun.


### E. Kunci Aktivitas 5 — Tips Keamanan
1) Password berbeda tiap akun 2) Aktifkan 2FA 3) Jangan klik link mencurigakan 4) Hati-hati sharing di medsos


### F. Kunci Aktivitas 6 — 2FA Setup
Praktik mengaktifkan 2FA di akun Google masing-masing.


### G. Kunci Aktivitas 7 — Analisis Password
"123456" -> sangat lemah (detik), "P@ssw0rd!" -> lemah (menit), "Saya$uka$Python2025" -> kuat (abad)
