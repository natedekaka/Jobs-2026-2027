## Aritmatika

`+` `-` `*` `/` `//` `%` `**`

```python
print(10 + 3)   # 13
print(10 // 3)  # 3
print(10 % 3)   # 1
print(2 ** 3)   # 8
```

---

## Perbandingan

`==` `!=` `>` `<` `>=` `<=`

Hasilnya selalu **True** atau **False**

```python
print(5 == 5)   # True
print(7 < 3)    # False
print(10 >= 10) # True
```

---

## Logika

`and` `or` `not`

```python
True and False → False
True or False  → True
not True       → False
```
