## Variabel = Kotak Penyimpanan

```python
nama = "Andi"    # string
umur = 17        # integer
tinggi = 165.5   # float
aktif = True     # boolean
```

---

## 4 Tipe Data Dasar

| Tipe | Contoh |
|---|---|
| `int` | 17, 2026, -5 |
| `float` | 3.14, 0.5 |
| `str` | "Halo", 'Python' |
| `bool` | True, False |

---

## input() dari User

```python
nama = input("Siapa namamu? ")
print("Halo", nama)
```

⚠️ input() selalu **string**!
Konversi: `int(input(...))`
