## IP Address = Alamat Rumah Digital

Setiap perangkat di internet punya IP unik

`192.168.1.1` → contoh IPv4

Cek IP: `ipconfig` (Windows)

---

## DNS = Buku Telepon Internet

```
google.com  →  142.250.64.78
youtube.com →  172.217.0.46
```

Kita ingat nama, komputer ingat angka

---

## Cara Kerja Web

```
User ketik URL → DNS → Request → Server → Halaman
```

1. Ketik google.com
2. DNS: google.com = IP
3. Request ke server
4. Server kirim halaman
5. Browser tampilkan

---

## Aktivitas 1 — Cek IP

Buka terminal, ketik `ipconfig` / `ifconfig`

---

## Aktivitas 2 — DNS Lookup

`nslookup google.com`

---

## Aktivitas 3 — Urutkan

5 langkah cara kerja web
