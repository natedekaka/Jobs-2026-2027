A. Konsep Perulangan (Loop)

Perulangan memungkinkan algoritma menjalankan blok instruksi berulang kali. Dalam flowchart, perulangan digambarkan dengan panah kembali ke langkah sebelumnya (back loop) atau memeriksa kembali kondisi pada belah ketupat.

JenisCiriKapan Digunakan
FORJumlah perulangan sudah diketahuiCetak 1–10 → 10 kali
WHILEBerhenti berdasarkan kondisiUlangi sampai tebakan benar
Repeat-UntilDijalankan minimal sekalido...while (jarang di flowchart dasar)
⚠️ Bahaya Infinite Loop
Jika kondisi tidak pernah menjadi salah, perulangan tidak pernah berhenti — disebut infinite loop. Selalu pastikan ada langkah yang mengubah kondisi!

B. Flowchart FOR Loop

Contoh 2 — Cetak Bilangan Genap 2–10: i mulai dari 2, tambah 2 setiap loop: 2, 4, 6, 8, 10.

C. Flowchart WHILE Loop

Contoh 3 — Hitung Mundur: Start → input n → n > 0? → Ya → output n → n = n − 1 → kembali ke kondisi; Tidak → output 'Go!' → End.

Contoh 4 — Tebak Angka: Start → komputer = random 1–10 → input tebakan → tebakan != komputer? → Ya → input tebakan lagi → kembali; Tidak → output 'Benar!' → End. (Ini WHILE: berhenti saat tebakan benar.)

D. Akumulasi (Running Total)

Contoh 5 — Jumlah 1–100: total = 0 → i = 1 → i <= 100? → Ya → total = total + i → i = i + 1 → kembali; Tidak → output total → End. Hasil: 5050.

Contoh 6 — Rata-rata N Nilai: input n → total = 0 → i = 1 → i <= n? → Ya → input nilai → total = total + nilai → i = i + 1 → kembali; Tidak → rata = total / n → output rata → End.

Contoh 7 — Faktorial n!: input n → faktorial = 1 → i = 1 → i <= n? → Ya → faktorial = faktorial × i → i = i + 1 → kembali; Tidak → output faktorial → End. Tracing: n=5 → 1×2×3×4×5 = 120.

E. Loop Bersarang (Nested Loop)

Contoh 8 — Tabel Perkalian 3×3: baris = 1 → baris <= 3? → Ya → kolom = 1 → kolom <= 3? → Ya → hitung = baris × kolom → output hitung → kolom = kolom + 1 → kembali; Tidak → baris = baris + 1 → kembali; Tidak → End.

Cara membacanya: untuk setiap baris, jalankan seluruh kolom. Total iterasi = 3 × 3 = 9 kali.

📝 Contoh Soal & Penyelesaian

❓ Buat flowchart mencetak bilangan ganjil 1–19!
Jawaban: Start → i = 1 → i <= 19? → Ya → output i → i = i + 2 → kembali; Tidak → End. Output: 1, 3, 5, ..., 19.
❓ Buat flowchart menghitung jumlah bilangan genap 1–50!
Jawaban: Start → total = 0 → i = 2 → i <= 50? → Ya → total = total + i → i = i + 2 → kembali; Tidak → output total → End. Hasil = 2+4+...+50 = 650.
❓ Buat flowchart menghitung faktorial n! (n × (n−1) × ... × 1)!
Jawaban: Start → input n → faktorial = 1 → i = 1 → i <= n? → Ya → faktorial = faktorial × i → i = i + 1 → kembali; Tidak → output faktorial → End. Tracing: 6! = 720.
❓ Buat flowchart mencetak pola bintang segitiga siku-siku (3 baris)!
Jawaban: Start → baris = 1 → baris <= 3? → Ya → kolom = 1 → kolom <= baris? → Ya → output '*' → kolom = kolom + 1 → kembali; Tidak → baris = baris + 1 → kembali; Tidak → End. Output: *, , *.
❓ Buat flowchart menu: pilih 1–4, ulang sampai pilih 4 (keluar)!
Jawaban: Start → output menu → input pilihan → pilihan == 4? → Tidak → jalankan proses sesuai pilihan → kembali ke output menu; Ya → output 'Terima kasih' → End. (Pola WHILE berbasis menu.)

🚫 Miskonsepsi & Kesalahan Umum

Miskonsepsi / KesalahanFakta yang Benar
Lupa update counter (i = i + 1)Tanpa update, loop tidak pernah berhenti (infinite)
FOR dan WHILE tidak dibedakanFOR: jumlah pasti; WHILE: berdasarkan kondisi
Kondisi salah arah (menggunakan < bukan <=)Periksa batas: untuk 1–5 gunakan i <= 5
Reset akumulator di dalam looptotal = 0 diletakkan sebelum loop, bukan di dalam
Loop bersarang tidak memahami urutanLoop dalam diselesaikan penuh untuk tiap iterasi loop luar

🔑 Rangkuman Kunci

Poin penting pertemuan ini:
• Perulangan menjalankan blok instruksi berulang kali. • FOR = jumlah perulangan diketahui; WHILE = berhenti berdasarkan kondisi. • Panah kembali (back loop) adalah penanda perulangan di flowchart. • Akumulator (total = total + i) menghitung jumlah kumulatif; inisialisasi di luar loop. • Nested loop: loop dalam selesai penuh untuk setiap iterasi loop luar. • Selalu update counter agar terhindar dari infinite loop.
